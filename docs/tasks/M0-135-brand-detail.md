# M0-135 品牌详情

2026-11-24。 [Issue #135](https://github.com/Godyu97/geo-pro/issues/135) · [视觉验收清单](../08-验收场景与样例.md#ui-visual-checks) · [S-M0-01 品牌管理补充](../specs/M0.md#s-m0-01)

品牌负责人打开品牌详情后，应能先看到品牌名称、最新实体版本，以及当前监测准备的下一步。自然发现题不足时，下一步是去确认题目。历史版本的主要动作是回到当前版本。读取失败时保留标题，不显示品牌正文，并用键盘重新载入。

基线 `5e8dc78ace9664105e55f305e510086afd484ffd` 在隔离 Chrome 中文 375 像素复现：长说明和长网址把「自然发现题少于 3 道。去确认题目。」留在资料区之后，滚动到页首后可见比例为 0。

- `/dashboard/brands/[id]` 留在工作台唯一的 `main#main-content` 内。标题是品牌名称。任务说明、实体版本和状态放在同一内容区。相关入口换行，包含返回品牌资料、事实与材料、监测问题和本地观察等入口。
- 主要动作是监测准备的当前下一步。可以确认运行时，动作是确认此品牌的监测运行。正在查看历史版本时，动作是查看当前版本。准备状态暂时读不到时，动作是重新加载，并保留追踪编号。
- 一句话业务、官网、别名和问题草稿在字段内换行。监测准备明细仍列出题集、通道、额度和事实计数，已放到页首的下一步不再重复出现。
- 品牌资料读取失败时标题仍是品牌资料，提示可重试，主要动作是重新载入当前地址。不显示名称和网址。其他账号打开同一地址仍是找不到页面，看不到这些内容。
