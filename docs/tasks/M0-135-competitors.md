# M0-135 竞品与来源

2026-11-24。 [Issue #135](https://github.com/Godyu97/geo-pro/issues/135) · [视觉验收清单](../08-验收场景与样例.md#ui-visual-checks) · [S-M1-02 与 AC-M1-02-1/2/3](../specs/M1.md#s-m1-02) · [指标与证据合同](../07-指标与证据合同.md)

品牌负责人从 AI 回答进入竞品与来源后，应能看出当前品牌、保存固定竞品集，并读到计次、分母和份额。没有已记录提及时，页面不写成无序排名。同一回答重复保存仍是每品牌一次。引用正文不可读时，引用还在，支持性保持未知。只替换对方品牌名的 Brief 不保存。

基线 `4de331365b0ce1c0adfecdbac1a221af8a09b88c` 在隔离 Chrome 中文 375 像素复现：还没有竞品集时，份额区已经显示「这些提及没有明确顺序，不显示排名。」页面也不显示当前品牌。随后用 160 字引用地址选择来源时，多选控件一直等不到可操作状态，用例在 180 秒超时。长名称先把计次、分母和份额挤出 375 像素首屏。

- `/dashboard/monitoring/competitors` 留在工作台唯一的 `main#main-content` 内。标题、品牌名、任务说明和相关入口放在同一内容区。相关入口换行，包含返回 AI 回答和监测概览。
- 没有品牌时保留标题，主要动作是前往品牌。找不到版本或品牌时保留标题，不显示名称和引用，恢复动作是查看当前品牌；当前账号没有活跃品牌时改为前往品牌。
- 份额表使用固定列宽。名称在单元格内换行，计次、分母和份额留在同一视口。没有提及时只显示 0 和 N/A，不显示无序说明。已有无序提及时才写明不排名。
- 引用卡片保留完整地址。下拉选项超过 72 字时截断显示，避免长地址把选择控件撑到无法操作。复核和 Brief 仍使用引用编号，不抓取外部网页。

## 隔离验收

Chrome 使用迁移后的临时 PostgreSQL、memory 缓存、回环 S3 和邮件 Mock。品牌、回答和引用都是合成数据。

| 场景 | 实际结果 |
| --- | --- |
| 从回答进入 | 中文 375 像素用 Enter 打开「竞品与来源」。页首可见品牌「合成竞品验收」和「保存竞品集」，且保存按钮在视口内。此时没有无序说明。 |
| 份额 | 保存 40 字名称和「甲品牌」后，两行都是计次 0、分母 0、份额 N/A。同一回答勾选两个名称并保存两次，计次和分母都是 1，份额是 1。页面写明不显示排名，没有条件平均位置。 |
| 受限引用 | 完整地址仍在卡片中。勾选页面可打开和正文支持本品牌、不勾选正文可读后，状态为正文受限，支持性未知，没有「页面支持品牌」。域名行写明不是平台偏好。 |
| Brief | 只把「甲品牌」换成「乙品牌」的角度没有保存，并显示拒绝原因。补上缺口和来源后可以保存。英文 375 像素用 Enter 接受，状态变为 Accepted，接受和搁置按钮消失。 |
| 双语和宽度 | `zh-CN` 与 `en` 在 375、768、1440 像素无横向溢出，且只有一个 `main`。375 像素的计次单元格右边缘仍在视口内。份额表可聚焦，焦点可见。 |
| 缺失版本 | 英文 375 像素打开不存在的版本时保留标题和未找到提示，看不到名称和引用。Enter「View the current brand」后回到已保存的名称。 |
| 其他账号 | 写入该品牌的人工证据返回 404。英文 375 像素看不到名称和引用，主要动作是前往品牌。无品牌入口同样如此。 |
