## 做了什么

- mock 模式可以给当前品牌写入一条采样额度。额度原因使用现有枚举 `correction`，因为合同里没有 mock 原因。它不是试点批准。
- 额度是 CNY 3000 分、30 次，30 天后过期。已有未过期额度会复用，不覆盖其他币种。
- 运行详情在 mock 模式提供「执行 mock 采样」。只有槽位通道的 `vendorId` 全是 `functional-mock` 才执行。回答走隔离传输，`synthetic` 为真，原文带 `[FUNCTIONAL-MOCK]`。
- 开关关闭或通道不是 mock 时，接口返回 `REAL_CHANNEL_CLOSED`，不生成结果。

## Mock 边界

没有真实供应商、可信价格或真实结果。官方轨仍要满足现有邮箱校验和费用上限。消费者轨不扣这份额度。正式运行确认接口仍然返回 `RUN_NOT_OPEN`。

## 不能当作真实验收

不勾选 T-M0-05。mock 回答不能写成真实监测。
