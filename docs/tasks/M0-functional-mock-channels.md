## 做了什么

- mock 模式下，工作台可以写入两条通道：`model_api` 与 `consumer_ui`，`vendorId` 为 `functional-mock`。
- 显示名、限制和 SOP 都带 `[FUNCTIONAL-MOCK]`。`publicVisible` 为 0，不进入公开投影。
- 官方 API 的合成单价是 CNY 1 分/次。没有 HTTP 请求，没有凭据，没有真实账单。
- 已有未过期的同名 mock 通道会复用。只有非 mock 的已验证通道才会显示「可用于正式运行确认」。

## Mock 边界

没有可授权的官方 API，没有可实走的消费者入口。维护授权没有被授予。写入只发生在功能性 mock 开关打开时，并且不经过真实供应商适配器。
