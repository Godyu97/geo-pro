# Issue #198 实体复核和纠错品牌授权

2026-11-27。 [Issue #198](https://github.com/Godyu97/geo-pro/issues/198) · [S-M1-03](../specs/M1.md#s-m1-03) · [S-M1-08](../specs/M1.md#s-m1-08)

## 交付

- 品牌详情向获准成员展示抽样错误率、同名消歧与纠错入口。两个页面及其 API、Server Actions 沿用品牌读写授权。只读成员可查看主张、看板和已有记录。组外和已撤销成员无法读取。两个工作区的回答列表链接保留所选品牌。
- 在写事务中检查授权。复核、消歧、纠错继续储存在品牌负责人数据范围内，消歧生成的新分析版本记录实际操作者。消歧保留旧分析版本的全部字段，提交成功后失效品牌负责人的证据概览缓存。
- 复核批次一次查询核对观察和分析版本。确认错误还要求该条复核基于最新分析版本，且与有效事实存在可确认的冲突。过期、缺证据或版本不符的确认请求被拒绝。更正仍追加新复核，纠错的动作与效果分列。
