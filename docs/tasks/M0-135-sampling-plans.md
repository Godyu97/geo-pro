# M0-135 采样计划页

2026-11-24。 [Issue #135](https://github.com/Godyu97/geo-pro/issues/135) · [视觉验收清单](../08-验收场景与样例.md#ui-visual-checks) · [S-M1-01 与 AC-M1-01-1/2/3](../specs/M1.md#s-m1-01) · [指标与证据合同](../07-指标与证据合同.md)

品牌负责人从监测概览进入采样计划后，可以先看已有计划的阶段和预算，读到期题单，或打开已登记的官方运行。基线 `2e74cf2653f00ec418413b8c7efd454624d9251b` 在临时 PostgreSQL 的 Chrome 中文界面复现了布局缺口。375 × 800 像素下，计划版本标题在视口内的可见比例为 0。

- `/dashboard/monitoring/plans` 在已有计划之前显示当前品牌和页面任务。新建表单放在计划之后，页首保留直接跳转。计划卡片显示阶段、版本、预算、已花费和待对账，金额沿用计划所存币种的最小单位。
- 有运行编号的已登记官方槽位提供运行详情链接，打开后沿用运行详情的会话和品牌归属校验。人工题单保留原文、题目编号和缺失提示。槽位区域可用键盘聚焦和横向滚动。
- 到期处理沿用现有服务端动作。计划页展示处理结果、预算暂停和窗口读数，供应商调用由受控运行处理。

- 使用生产构建启动回环开发站。独立临时账号在 375 像素下通过双语无品牌状态和 Enter 前往品牌，查询其他账号的计划返回 404。账号和会话已清理并回读确认。本轮未请求供应商。
