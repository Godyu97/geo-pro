2026-11-24。 [Issue #136](https://github.com/Godyu97/geo-pro/issues/136) · [S-M0-07](../specs/M0.md#s-m0-07) 第 4 条 · [PAGE-02](../02-产品需求文档-PRD.md)

## 交付范围

- 品牌负责人打开 `/dashboard` 时，按自己的活跃品牌读取证据概览的默认范围：官方 API 轨道，不额外收窄地区、联网或时间。三项比率与同一范围的 `/dashboard/monitoring/overview` 使用同一读模型。
- 没有活跃品牌时，主动作是前往品牌，不展示指标、建议或其他账号的数据。没有合格样本时，提及、推荐和官网引用显示 N/A、原因和启动监测。有样本时显示题等权比率、小样本说明和官网不适用原因。
- 优先建议最多 3 条。状态为进行中或阻塞的已有任务另行列出。没有建议或没有这类任务时保留空态，不补造条目。优先级和状态使用 `zh-CN` / `en` 文案。品牌、监测概览、优化、内容和报告入口从总览可以到达。
- 带 `[FUNCTIONAL-MOCK]` 的演示正文不进入比率，总览不写入演示数字。本记录不勾选 T-M0-07，也不把阶段门禁记为通过。
