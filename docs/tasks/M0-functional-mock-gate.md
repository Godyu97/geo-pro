# 功能性 mock：阶段门禁试算

[T-M0-GATE](M0.md#t-m0-gate) 保持未勾选。

## 做了什么

- mock 模式的报告页调用现有 `m0StageGate`。
- 输入固定为：真实品牌否、官方回答 0、消费者回答 0、独立完成 0。
- 页面展示函数返回的未通过原因。函数本身没有改动：官方回答少于 20、消费者回答少于 6、独立完成数少于 4 时拒绝。

## Mock 边界

这四项输入是标明的 0，不是试点计数，也不是走查人数。函数即使返回通过，页面文案也写明那不是阶段验收。

## 不能当作真实验收

不勾选 T-M0-GATE。产品合同第 6 项仍要求 5 名真实用户。本次没有降低阈值，没有填写 5 人走查表，也没有把试算写成已验收。
