# Issue #138 概览覆盖、自有页引用与最后采集

2026-11-24。 [Issue #138](https://github.com/Godyu97/geo-pro/issues/138) · [S-M0-07](../specs/M0.md#s-m0-07) · [指标合同](../07-指标与证据合同.md) 第 2、3 节

## 交付范围

- 品牌负责人在 `/dashboard/monitoring/overview` 和 `/dashboard` 看到与当前轨道、目标地区、请求联网和采集时间相同的计划覆盖。P 只计所选范围内已到期的非草稿采样计划槽位。失败和已暂停留在分母，未来槽位不计入。没有可关联槽位时覆盖为 N/A，并说明没有冻结计划槽位。
- 条件合格 E 只计证据完整或已争议、引用集合完整，且已保存采样条件满足的槽位。请求联网为开或协议要求联网、但触发未知时，该槽位不合格，并计入联网未知。
- 提及和推荐仍用原有题等权。卡片同时给出可判断分母和未知比例。分母为 0 时显示 N/A，不写成 0%。
- 官网引用继续使用已确认的官网判定。自有页引用只看 `owned_domain` 或 `owned_account`。未知归属不记为未引用，也不并入官网引用率。没有可判断自有页引用时显示 N/A 和原因。
- 所选范围内有完整证据时显示最近的采集时间。没有完整证据时显示尚无有效采集，已能计算的主指标仍在。关联能力版本的 `expiresAt` 已过时，同时标出过期。
- 概览建议、优化任务列表和详情上的优先级与状态使用界面语言。
- 不改题等权公式，不新增综合分，不勾选阶段门禁。

## 查询路径

计划关联从 `sampling_due_run_owner_idx` 的 `owner_id` 进入，再按品牌过滤，并左连运行与冻结协议。引用归属按观测 ID 分块读取；单条探测走 `answer_citation_observation_idx`，品牌条件留在 Filter。能力过期读取 `capability_version` 主键上的版本行，取每个通道的最新 `expiresAt`。概览样本查询仍用 `answer_observation_owner_idx`。没有新增表或索引。

隔离缓存对比中，30 条样本 11 次 SQL，120 条样本 13 次 SQL，命中为 1 次。增加的是按品牌取计划和按观测分块取引用，不随样本线性增长。这些次数是合成夹具，不是客户延迟。
