# #135 品牌委托页

2026-11-25。品牌负责人从「账户设置 → 品牌委托」进入后，可从页首登记授权、管理有效委托或查看历史。代理成员可打开组合看板查看授权范围。尚无品牌或委托的账号可从页首开始登记组织成员。

本轮覆盖 [全站视觉验收](../08-验收场景与样例.md#ui-visual-checks) 的入口、状态反馈、键盘和双语响应式场景，以及 [S-M2-03](../specs/M2.md#s-m2-03) 的 AC-M2-03-1 本地授权路径。

## 实现与复用

- 页首使用共享按钮，跳转后把焦点交给登记字段或对应章节标题。负责人卡片显示品牌、组织标识、UTC 到期时间及有效、自然到期或已结束状态。当前不能登记的品牌历史用品牌标识定位。代理组合页按现有授权范围显示证据标识。
- 到期操作使用共享确认弹窗，说明失去证据访问权限、停止排队动作和保留历史记录的影响。登记和确认失败可原位重试。反馈随语言切换，读取失败可从页首重新载入。
- 基线 `0daa041faf127cd52af84f2ea389e744f6b617c3` 使用迁移后的隔离 PostgreSQL 和 Chrome。在中文 375 像素负责人页面，页首「开始登记委托」断言因找不到链接而失败。本地截图为 `.cache/issue-135/delegations/baseline-375.png`。

## 验收证据

- `zh-CN` 和 `en` 各在 375、768、1440 像素走查负责人无委托、有委托与历史，以及代理无品牌、有效范围和已阻塞状态。账户设置位置可见，主内容区唯一，页首操作完整位于视口，页面无横向溢出。长品牌名和证据标识可在卡片内换行。原生品牌下拉框收起时会截断长选项。
- 代理账号用键盘登记成员，数据库读回有效。负责人通过页首入口聚焦品牌字段。无效证据标识被拒绝，登记遇到 503 时保留输入与按钮焦点。切换英文后提示更新，组织标识、UTC 时间和范围仍可重试。成功后清空表单，回读得到相同的范围、到期时间和排队动作。代理方只看到获授的证据标识，第三账号读取、结束或执行均返回 404。
- 两种语言的到期弹窗先聚焦取消。按 Escape 返回触发按钮，无持久化写入。确认遇到 503 后可在同一按钮重试，成功后焦点回到品牌标题。数据库保留委托及原到期时间，动作变为停止，组织成员仍有效。代理读取返回 403，再提交队列动作得到同一条已停止记录，无证据标识。另以同一测试品牌的第二份委托模拟自然到期，负责人可看到已到期，代理读取同样返回 403。
- 两种语言在 375 像素验证加载提示、读取故障与键盘恢复。故障由浏览器测试在应用副本注入，界面隐藏记录、表单和内部异常。测试仅操作临时账号及合成数据，结束后回读确认临时账号、品牌、版本、成员和委托已清理。
