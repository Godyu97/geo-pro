品牌负责人在 `/dashboard/reports` 阅读已经生成的同口径快照。页面和此后新生成的 HTML 按各指标已保存的 `conclusion` 显示观察改善、观察下降、无变化或无法判断，并写明不建立因果。执行成果、可见性、爬虫访问和去重咨询分开出现。已保存的 JSON 与 HTML 字节保持不变。

## 范围

- 正变化显示观察改善，负变化显示观察下降，无变化显示无变化，无法判断显示无法判断。无法判断不写成无效果。不可比较保持不可比较，不改写成观察改善。
- 提及、推荐和官网引用各自使用已保存的共同题数、百分点差和结论。百分点差仍按已保存数值格式化，不随结论标签重算，也不展示相对增幅。
- 四层只读已保存字段：核验发布或诊断复跑、三项可见性比较、爬虫访问、去重咨询与转化率。爬虫访问保持 `called_included: false`，不写成被 AI 收录。某一层没有保存时显示缺失和原因，不补 0。
- 界面 `zh-CN` / `en` 都提供这些句子。新 HTML 使用生成时的快照语言；报告页按当前界面语言从已保存枚举派生，不改下载字节。
- 不勾选 T-M0-12 或 T-M0-GATE。
