# #192 行业题包审核与监测草稿采纳

2026-11-27 · [Issue #192](https://github.com/Godyu97/geo-pro/issues/192) · [行业题包规格](../specs/M2.md#s-m2-06) · [监测题集规格](../specs/M0.md#s-m0-03)

## 实现与边界

- 题包有草稿题时，具备品牌写权的负责人或成员可以标记为已审核，再将题包标为可用或停用。可用题包也可以停用。已审核与可用状态允许按题目勾选，可从同品牌监测问题页进入题包页，并返回监测草稿。
- 采纳复用题集保存规则。候选保留题目原文、题包来源和题目 ID，重复提交同一题目不会增加草稿行。追加时保留已有草稿题目和基线版本，监测题集冻结由用户在原入口发起。
- 未覆盖的监管场景在生成前和采纳前拦截。只读用户可浏览获准品牌的题包，跨组管理员可打开指定活跃品牌的题包查阅。越权请求返回资源未找到。
- 复用现有行业题包及监测题集草稿表。行业题包列表以授权品牌集合查询，每次各执行 1 条题包查询和 1 条关联题目查询，单包题目限额独立。SQLite3 / PostgreSQL 隔离测试核对 `industry_pack_owner_brand_idx` 与 `industry_pack_question_pack_idx` 查询计划，并验证并发重放、整批拒绝和历史快照保持。
