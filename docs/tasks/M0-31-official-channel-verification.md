# M0-31 官方 API 非联网通道核验

Issue [#31](https://github.com/Godyu97/geo-pro/issues/31)｜2026-11-23｜核验时 Git `e8b21a4`。本记录只覆盖开发环境中已配置官方采样通道的非联网层级。不勾选 T-M0-04，不勾选 AC-M0-GATE。消费者入口和站内执行入证仍未完成。

## 范围与决定

- 使用 `GEO_OFFICIAL_SAMPLING_*`。不把 `OPENAI_*` 单独当成采样通道。单价表币种 CNY，模型 `deepseek-flash`，输入 100、输出 200 个最小货币单位 / 百万 token。产品入口是 `official-responses-dev`，不是可打开的消费者地址。
- 模型目录 `GET /models` 返回 HTTP 200，目录 1 个模型，与单价表一致。
- 单次费用上界 20，本批上界 100，均按单价表和响应 usage 向上取整。没有供应商发票，缺 usage、模型不一致或超过上界时不会记为已知费用。
- 10 道固定非品牌题各 2 轮，请求联网 `off`，`store: false`。20 次均为 HTTP 200、`adopted`、实际 1 个最小货币单位、触发 `not_triggered`、`annotations` 为空数组。适配器把空引用集记为 `complete`，URL 数为 0。
- 另有一次联网 `on` 试探：HTTP 200，费用 1，输出里没有 `web_search_call`，触发记 `unknown`。因此 `searchRequired` 保持 0，不开放 required 联网分母。
- 两次试探加 20 次正式调用合计 22 个 CNY 最小货币单位。试探原文未保留，正式 20 次原文见下表。这些回答只证明通道可返回文本，不构成品牌监测样本或排名。
