# Issue #170 官方通道版本与证据范围

2026-11-26。 [Issue #170](https://github.com/Godyu97/geo-pro/issues/170) · [S-M0-07](../specs/M0.md#s-m0-07) · [T-M0-07](M0.md#t-m0-07) · [指标与证据合同](../07-指标与证据合同.md) 第 1–4 节

## 交付

- 品牌负责人可在概览与回答列表选定官方通道的冻结版本。页面和两条读取 API 共用 `channel=<通道 ID>@<版本>`，按目标地区、请求联网和采集窗口叠加筛选。回答详情返回时保留版本、列表筛选与原文锚点。历史记录可用 `channel=unknown` 查看。自动范围遇到多个来源组时提示选版本，概览与工作台摘要暂停展示汇总。
- 版本取自同品牌、同所有者、同轨道的冻结运行槽位。P 以已到期的采样计划槽位为单位。选定版本时，通过到期登记及其运行中该通道的唯一冻结版本归属。已失败的可归属计划槽位计入 P。演示原文在查询层排除，版本候选和回答聚合共用该约束。
- 已完成的官方原文可下钻。要求联网但实测触发未知时，该原文仍可查，覆盖记录待核对。符合协议的样本独立计算提及和推荐，官网及自有页引用还要求引用集合完整。零分母显示 N/A，引用集合全部缺失或不完整时给出对应原因。
- 同一版本的概览、逐题、计划覆盖与回答使用同一读取服务。缓存键包含版本范围，归属核验在缓存读取前执行。采样计划与运行建立关联后，读取令牌更新。
