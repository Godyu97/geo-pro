# M0-135 渠道变体

2026-11-24。 [Issue #135](https://github.com/Godyu97/geo-pro/issues/135) · [视觉验收清单](../08-验收场景与样例.md#ui-visual-checks) · [S-M1-05](../specs/M1.md#s-m1-05)

品牌负责人打开渠道变体后，应能先看到当前任务和下一步。正文与主稿不同时，先核对并保存草稿，不能继承主稿批准，导出也不是下一步。正文与主稿一致但还没有单独批准时，下一步是单独批准。已有单独批准且正文一致时，下一步才是导出。读取失败时保留标题，不显示稿名、渠道和正文，并用键盘重新载入。

基线 `f8a08143f5d04de690b62ab62f168a18f66e5dce` 在隔离 Chrome 中文 375 像素复现。页面没有说明下一步。180 字无空格标题和长说明占满首屏，保存、单独批准和导出都排在正文框之后。

- `/dashboard/content/versions/[versionId]/variants` 留在工作台唯一的 `main#main-content` 内。标题是渠道变体。任务说明放在同一内容区。相关入口换行，包含返回稿件、渠道画像和事实与材料。
- 还没有变体时，主要动作是保存渠道草稿。正文与主稿不同时，主要动作仍是保存渠道草稿，并且不提供导出。正文一致但尚未单独批准时，主要动作改为单独批准该变体，仍然不提供导出。已有单独批准且正文一致时，主要动作才是导出该变体。主稿未批准或渠道已受阻时，主要动作是返回稿件。
- 稿名在内容区内换行。变体列表保留渠道、画像钉选和拒绝原因。导出不出现在还不能导出的状态里。
- 读取失败时标题仍是渠道变体，提示可重试，主要动作是重新载入当前地址。不显示稿名、渠道和正文。其他账号打开同一地址仍是找不到页面。

## 隔离验收

Chrome 使用开发用回环 PostgreSQL、memory 缓存、回环 S3 和邮件 Mock。品牌、事实、稿件和画像都是合成数据。本轮没有请求供应商，也没有点击导出，因此没有写入交付包。

| 场景 | 实际结果 |
| --- | --- |
| 正文不同 | `zh-CN` 与 `en` 在 375、768、1440 像素无横向溢出，且只有一个 `main`。中文可见「这条变体的正文与主稿不同，不能继承主稿批准，也不能导出已批准包。下一步是核对正文后保存草稿。」主要动作「保存渠道草稿」只出现一次，375 像素在视口内。没有「导出该变体」。渠道 `zhihu` 是草稿，拒绝原因写明需要独立重审。180 字稿名留在标题字段内。中文 375 像素用 Enter 保存后，说明仍是正文不同，并显示草稿已保存。 |
| 尚未单独批准 | 把正文改回与主稿一致后，同一两种语言和三种宽度无横向溢出。主要动作是「单独批准该变体」，375 像素在视口内。没有导出按钮。中文 375 像素用 Enter 批准后，说明改为可以导出，状态是已单独批准。接口回读 `approvalStatus` 为 `approved`，`rejection` 为 null，正文与主稿一致。 |
| 可以导出 | 批准后的 `zh-CN` 与 `en` 在 375、768、1440 像素无横向溢出。「导出该变体」只出现一次，375 像素在视口内。没有「单独批准该变体」。本轮没有点击导出。 |
| 读取失败 | 英文 375 像素保留标题 Channel variants 和失败提示，看不到长稿名、`zhihu` 和改过的价格。重新载入在视口内。清除故障标记后用 Enter 回到原变体，导出说明和长稿名仍在。 |
| 其他账号 | 英文 375 像素显示 Page not found，看不到长稿名和渠道。 |

六张 375 像素截图使用合成数据，保存在本地 `.cache/issue-135/channel-variants/`，可由 `tests/e2e/channel-variants.spec.ts` 重新生成。清理后回读，邮箱前缀 `content-variant-` 的账号、名称为「合成变体品牌」的版本，以及正文仍含「合成说明售价 101 CNY」的 `zhihu` 变体都是 0 行。浏览器没有单独打开还没有变体、主稿未批准或渠道已受阻的页面；这三步写在页面分支中。
