# #177 图片使用权与内容交付

对应 [Issue #177](https://github.com/Godyu97/geo-pro/issues/177)、[S-M1-04](../specs/M1.md#s-m1-04) 的 AC-M1-04-2 和 [S-M0-10](../specs/M0.md#s-m0-10) 的 AC-M0-10-3。

## 交付范围

- 从内容列表批量预检、稿件详情单稿预检和渠道变体页都能查看失效图片的名称、引用版本和原因，并进入稿件更换图片。确认导出重查使用权。合格子集仍需用户明确确认。
- 从稿件上传公开图片后，用同一 ID 登记原文件与使用权。稿件保存图片清单时固定素材版本。换图或移除图片保留引用和待办，原正式批准失效，复审后可重新导出。
- PostgreSQL 和 SQLite 的 `image_asset_use` 增加 `superseded_at` 与当前引用索引。已有明确登记的引用仍参与校验。历史上传和独立台账条目通过各自的原有 ID 保留，使用权联动依赖已登记的明确关联。撤销或标记到期会将关联的已发交付包标为勿再使用，保留只读归档。

## 开发验收

正式验收复用已持久化的开发品牌、负责人、只读及外部账号，使用实际的 PostgreSQL、Redis 和私有对象存储。素材使用仓库内用于项目的设计图，仅在开发环境交付。

| 入口和动作 | 结果 |
| --- | --- |
| 基线 `12acd241adfb6a8ed2010569f27fd1f6c031bb4b` 的稿件详情 | 原台账引用已撤销且有 1 条待办，预检仍判定为可导出。稿件尾号 `c0d23f2b` |
| 新版同一稿件的单稿预检 | 已有撤销引用按文件名和固定版本显示，随后可用已登记图片替换。 |
| 图片素材台账撤销与旧预检确认 | 浏览器确认撤销素材 `…52b0c0e8`，回读有 1 条维护待办。旧预检的确认接口返回 422 并指出具体图片。原包标为勿再使用，撤销后没有新增交付包。 |
| 内容列表批量预检与渠道变体 | 运行批量预检和渠道变体导出，均显示文件名、固定版本与撤销原因。中英文分别走查 375、768、1440 像素。用键盘操作预检、撤销确认和导出。 |
| 更换图片并重审 | 重新选择已撤销图片会被拒绝。换用 `…b1a4709e` 后主稿和变体分别重审，换图前的预检不能继续使用。从正常页面导出并回读两份正式包 `…ff51498d`、`…93470120`，图片清单均只包含替换图片。原引用标为已从稿件移除，原待办保留。 |
| 权限 | 外部账号读取原稿及素材均返回 404。只读成员可读稿件，附件和权利引用为空。 |

## 工程验证

- `pnpm lint`、`pnpm typecheck`、`pnpm build` 通过。Lint 保留 5 条范围外的已有警告。
- `pnpm test:content` 67 项、`pnpm test:asset-reuse` 13 项通过，两个方言均执行。覆盖图片撤销、到期、明确合格子集、换图前预检失效、渠道独立重审和并发确认重放。预检按所选稿件集合批量查询引用，两库执行计划均使用 `image_asset_use_content_idx`。
- `pnpm db:generate`、`pnpm db:ddl`、`pnpm db:ddl:check` 通过。开发 PostgreSQL 增量迁移通过。隔离测试核对双方言迁移和空库全量 DDL。
- `pnpm check:i18n`、`pnpm test:i18n`、`pnpm check:feature-map` 和 `python docs/tools/validate_docs.py` 通过。
- `pnpm verify:maintenance` 通过，包含 SQLite 和 PostgreSQL 的 `pnpm verify:auth`。隔离 PostgreSQL、回环对象存储和 Chrome 的四个既有内容浏览器用例通过。

本单的开发环境验收已完成。下一步在二期整体验收中把已审核包接入人工发布、公开核验和复测。生产发布和外部渠道观察不属于本次验收。
