## 交付范围

- 品牌负责人在 `/dashboard/monitoring/overview` 的同一范围看到逐题表。每道固定题同时列出提及、推荐、官网引用和自有页引用的分子、分母和比率。
- 分母为 0 的格子显示 N/A，题目行保留。未知样本只出现在该项的未知计数，不并入 false，也不显示成 0%。
- 没有登记官网时，官网引用格保持 N/A，不显示 0%。自有页未知归属仍留在自有页未知数。
- 主卡题等权、样本池化、计划覆盖和未知比例沿用原口径。回答列表的关键词和判定只收窄列表，返回概览后这张表仍是原范围。
- `zh-CN` / `en` 都有表头、N/A 说明和未知计数。比率数字不随界面语言改变。窄屏在表格内部横向滚动。
- 不新增采样，不新增表，不改轨道、目标地区、请求联网或采集时间。本记录不勾选 T-M0-07 或 AC-M0-GATE。
