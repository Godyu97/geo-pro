## 做了什么

- mock 模式调用现有 `requestRetest` 与 `generateReport`。
- 前后窗口各三道样本，题号、题集版本、通道版本、协议和分析规则都是 `functional-mock`。同一品牌实体版本、同一 `model_api` 轨道、区域 `CN`。
- 前窗分子为 0，后窗分子为 1，分母都是 1。这些数字写在快照里，只为让比较函数能跑完。
- 品牌名写入快照时带 `[FUNCTIONAL-MOCK]`。不传 `publicationId` 或 `effectiveAt`，所以经营闭环保持未完成，也不创建 D+7 付费待办。
- 同一操作标识重复执行会返回已有复测和快照。

## Mock 边界

样本不是监测运行的真实回答，也不是消费者走查。前后差值不能写成效果、排名或提升比例。

[#147](https://github.com/Godyu97/geo-pro/issues/147) 的新快照从已保存的分析版本读取三项指标。功能性 mock 仍可演练生成和下载，虚拟观察没有对应分析，三个比较块显示 N/A。旧快照保留生成时的字节。

## 不能当作真实验收

不勾选 T-M0-12。没有真实前后采样，也没有获准发布的生效点。
