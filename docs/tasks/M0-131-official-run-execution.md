## 交付范围

- 品牌负责人在官方轨道的运行详情发起执行。服务端校验会话、同源、品牌归属、冻结通道版本、当前核验窗口、额度、可信单价和已验证邮箱。消费者轨道仍走人工录入，不调用官方 API。
- 官方路径在外部调用前提交一次槽位尝试和额度上限，调用放在事务外。同一执行内每个槽位最多领取一次。未超过租约的进行中尝试不会再次请求。租约过后的进行中尝试、超时和不明结果进入费用核对，预留保持占用。确认的安全失败可在额度上限内由后续执行重试。功能 mock 与隔离执行仍在同一事务内完成。
- 尝试保存原始文本、响应定位、引用状态、联网触发和实际费用。回执长度由写入前的校验限制在 2–8000 字符。SQLite 只追加可空列，以便迁移后的表结构与全量 DDL 一致。
