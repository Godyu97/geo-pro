# #135 通知端点页

2026-11-24。品牌负责人从「账户设置 → 通知端点」检查本地提醒。页首提供登记、查看有效端点、查看投递历史和无品牌时的建档入口。读取失败时保留页面标题，提供重新载入操作，隐藏端点、表单与内部错误。

对应 [视觉验收](../08-验收场景与样例.md#ui-visual-checks) 的页面覆盖、组件与状态、双语与响应式、数据与流程，以及 [S-M2-02](../specs/M2.md#s-m2-02) 的 AC-M2-02-3 本地路径。

## 变化与适用范围

- 有有效端点时，页首链接聚焦该端点标题。仅有已撤销端点时，链接聚焦可查历史的端点。登记链接聚焦表单品牌字段，长标签和哈希在卡片内换行。
- 撤销弹窗显示停止后续发送与保留历史的影响。键盘打开后先聚焦取消，关闭时回到撤销按钮。撤销成功后回到端点标题。
- 检查提醒的接口在原有端点记录外返回本次持久化的结果，供界面显示「本地允许发送」或「未发送」。历史达到现有读取上限时，旧记录仍可读，本次提示由本次回执决定。提醒正文仅用于本地判定，历史保留分类标记、哈希和 UTC 记录时间。
- 基线 `7dc715d4c756f7644dd4fd4e74e7b3a60753a8cf` 的首次复现沿用了浏览器的英文偏好，中文标题断言失败。明确指定 `zh-CN` 后，确认合成品牌负责人的 375 像素页面缺少「开始登记」链接。证据在本地 `.cache/issue-135/notification-endpoints/baseline-375.png`。

## 验收证据

- `zh-CN` 和 `en` 各在 375、768、1440 像素检查无端点、有效端点、仅剩已撤销端点和无品牌四种状态。工作台位置可见，主内容区唯一，页首操作完整落在视口内，无页面横向溢出。长品牌名称在卡片内换行，原生品牌下拉框收起时会截断长选项。
- 窄屏从账户设置进入，按 Enter 聚焦品牌字段，按 Tab 到登记按钮。模拟登记返回 503 后，输入和按钮焦点保留。切换英文时输入保留，错误提示更新。切回中文重试后登记成功，表单清空，数据库回读一条有效端点。
- 正常合成提醒记录为本地允许。带「客户原文」标记的合成提醒记录为未发送。中英文撤销弹窗按 Escape 关闭时返回触发按钮且无写入。确认首次返回 503 时焦点与数据保留。重试确认后焦点回到端点标题，下一条提醒记录为未发送，原两条记录逐字段回读一致。重复撤销无新增写入。
- 双库专项用 200 条较早的允许记录占满历史读取窗口，确认撤销后的新回执为未发送，并按回执编号读回本次哈希与状态。浏览器另核对合成正文未出现在回读卡片中。
- 双语窄屏核对加载、读取故障和重新载入。读取恢复后仍能查看原回执哈希。第二账号读取、登记、撤销和请求发送均无法访问原账户资源，接口返回 404。隔离库和配置的回环开发 PostgreSQL 都使用合成数据，临时账号、品牌、品牌版本、端点和投递已清理并回读确认。
