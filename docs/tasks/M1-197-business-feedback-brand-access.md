# Issue #197 业务反馈品牌授权

2026-11-27。 [Issue #197](https://github.com/Godyu97/geo-pro/issues/197) · [S-M1-07](../specs/M1.md#s-m1-07) · [S-M1-08](../specs/M1.md#s-m1-08)

复测与报告入口传递 `brandId`。脱敏线索、线索有效性和下轮问题建议的相关链接、返回及重新载入保留品牌。三个页面按会话核对品牌读取和写入职责。获准成员可预览及导入 CSV、维护和冻结规则、记录访问观察和生成问题草稿。只读成员可查看，写入返回 HTTP 403。跨组管理员通过显式品牌入口查看业务反馈。无授权账号访问品牌深链接或 API 返回 HTTP 404。

明细按记录主键定位品牌，服务端核对动作后使用品牌归属者读取和写入原台账。并发 CSV 导入沿用去重合同，规则保存按版本顺序写入。下轮问题草稿在调用模型前和保存前均重查授权。冻结题集、未知状态和原有表结构沿用现有合同。

## 开发环境实测

| 角色和入口 | 实际结果 |
| --- | --- |
| 持久化 `member` 从复测与报告进入三个子页 | 打开品牌 `674a4755…` 的相关链接和返回链接携带同一品牌。显式切到 `16234aa9…` 后，三个子页持续显示该品牌。Chrome 中英文各核对 375、768、1440 px，键盘可进入和返回，无横向溢出。 |
| `member` 在有效性页保存并冻结 | 规则 `b87fa9a9…` 第 1 版要求真实需求、目标行业和可跟进。保存及冻结接口均返回 200。刷新、列表 API 及原负责人回读均为已冻结，另一个品牌规则列表与操作前相同。 |
| `member` 在脱敏线索页按键盘预览 CSV | 一条使用不透明事件 ID 的验收样本进入预览，另一条含直接身份标识的样本进入拒绝行。预览前后台账均为 0。本次预览没有提交。 |
| `read_only`、`admin` 与 `outsider` | 只读成员和跨组管理员打开三个子页及对应读取 API 均为 200，可回读同一冻结规则，无写表单。抽测的导入、规则写入、观察和草稿 API 均拒绝写入并返回 403。无授权账号打开三个深链接及对应读取 API 均为 404，页面未显示品牌名，抽测写入 API 返回 404。 |

主品牌的开发台账、连接事件、访问观察、建议均为 0。正式 CSV 导入与回读、实际访问观察和真实线索生成草稿仍待获准来源。本轮开发库只保存了上述一版规则。取得该品牌的一条获准脱敏线索和可用汇总后，用持久化成员完成导入与回读，核对 Responses 调用预算后再生成草稿并回读。若有获准访问汇总，可同时核对观察记录。本轮没有供应商调用或新增费用。
