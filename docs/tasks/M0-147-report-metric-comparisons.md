# Issue #147 复测快照的三项独立比较

2026-11-25。 [Issue #147](https://github.com/Godyu97/geo-pro/issues/147) · [S-M0-12](../specs/M0.md#s-m0-12) · [指标合同](../07-指标与证据合同.md) 第 5 节

品牌负责人从“复测与报告”下载同一份不可变快照的 JSON 和 HTML。提及率、推荐率、官网引用率分别给出共同题、排除原因、前后可判断样本数、题等权值和百分点变化。至少有 3 道共同题的指标才显示探索变化。低于门槛的指标显示 N/A 和原因，仍保留可复算的逐题分子分母。

## 证据与兼容

- 生成与纠错按本人和品牌一次批量读取两窗的观察及当时最新的已保存分析版本。冻结题目、通道、协议、分析语义、目标和实际地区等条件参加匹配；窗口按采集时间筛选。无法匹配的条件、未保存的分析、未知判定、无法观察原生引用或该实体版本无官网均有相应排除记录。重复观察编号只计一次。其他品牌与不存在的观察只计入不可读取数量，文件中没有这些编号。
- 新文件使用 `report-v4`，JSON 保存分析版本、原始观察定位及已使用的分子分母，HTML 从同一份冻结数据渲染。调用方在原接口中传入的指标名、分子分母和范围描述不参与这三项计算。列表对仍可读取的单指标旧快照显示原指标名。纠错生成后继版本，旧 JSON、HTML 和费用字段按原指纹回读。
- 双方言查询计划通过 `answer_observation_owner_idx` 读取本人观察，限定品牌并批量关联冻结数据，再通过 `answer_analysis_brand_idx` 定位最新分析。隔离样本一次读取前后共 8 条观察，SQLite 实测 0.29 ms，PostgreSQL 实测 1.77 ms。费用与工时继续使用 [#139 的口径](M0-139-report-cost.md)。
