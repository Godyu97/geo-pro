# Issue #155 成员授权接入品牌读写与排队复检

2026-11-26。 [Issue #155](https://github.com/Godyu97/geo-pro/issues/155) · [S-M1-08](../specs/M1.md#s-m1-08)

有效 `member` 可以读取和操作已授权品牌的概览、内容、监测执行和报告。显式切换到未授权品牌时返回与资源不存在相同的结果，响应不包含该品牌名称。只读成员可以读取，不能写入、导出或下载附件和交付包。撤销或到期后，尚未执行的恢复、监测执行和对象下载在动作开始前被拒绝，已排队的批次和运行保持原状态。本记录不勾选 T-M1-08，也不把组织内授权写成代理委托。

## 入口

- 证据概览、回答、内容和报告在省略品牌时进入当前操作者可访问的品牌；带上未授权的 `brandId` 时显示找不到资源，不回退到其他品牌。
- 品牌详情只对可读授权开放。编辑、状态、实体复核和删除仍只给负责人。
- 团队页可以授予 `read_only`。运营成员仍是 `member`。

## 验证

隔离库覆盖 SQLite 与 PostgreSQL。成员可以列出品牌甲的内容并读到证据概览中的品牌甲名称；品牌乙返回 `NOT_FOUND`，结果不含品牌乙名称。同时导出甲和乙得到空结果。只读成员不能导出或下载附件。撤销后暂停批次保持暂停，未执行的监测运行保持 `queued`，附件下载返回 `not-found` 且不含正文。到期后的只读授权同样返回 `NOT_FOUND`。授权查询使用 `brand_member_grant_pair_uidx` 或 `brand_member_grant_brand_idx`。

浏览器里用两个登录账号走查 `?brandId=` 尚未执行。没有可用的浏览器工具。解除条件是开发环境中的两名已登录账号分别打开已授权品牌，再把地址改到对方品牌并确认页面不出现对方名称。
