## 交付

- 品牌负责人或有编辑权限的成员从原件库选择一个可读片段，即可打开该片段对应的待确认事实卡。重复操作打开同一事实的当前版本。
- 事实卡保留私有原件的文件名、片段原文及已有页码。没有页码时显示缺失，用户可填写其他准确出处。用户单独填写主张、可公开摘录、来源日期、许可和有效期，并显式确认。启用双人审核时，录入或修改候选的操作者不能确认该版本。
- 内容 Brief、生成和交付使用现有事实门禁，仅采用已确认且有有效来源的事实。原件到期或撤销后隐藏原文并阻断新增内容使用。正式包只包含人工确认后的公开摘录与出处信息，附件及私有片段原文留在授权工作台。
