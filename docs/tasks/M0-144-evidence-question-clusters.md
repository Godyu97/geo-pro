# Issue #144 证据概览按主要问题簇汇总

2026-11-25。对应 R-M0-07、S-M0-07 第 1、2 条和指标合同第 4 节。 [Issue #144](https://github.com/Godyu97/geo-pro/issues/144) · [规格](../specs/M0.md#s-m0-07) · [指标合同](../07-指标与证据合同.md)

品牌负责人查看同一范围内的回答后，可在主卡下按问题簇比较提及、推荐和官网引用，再进入该簇的原文列表。每项单独显示已覆盖题数及该簇固定题数。分母为零的格显示 N/A 和原因，逐题明细保留该题及其所属组。

## 计算与读取

- 按既有概览的固定题键和三项逐题比率计算簇均值。每个有可判断样本的题权重为一。逐题比率为 N/A 的题仍计入簇固定题数。全范围主卡继续独立使用全部合格固定题。
- 有监测槽位时按关联运行的冻结题集解析，优先使用题号。无槽位时复用回答列表的最新题集文本匹配。无法解析或同一固定题跨版本解析出不同簇时，该题只在缺失组汇总。回答列表仍按各条证据的题集解读其簇归属。
- 范围查询在原槽位关联上按归属连接运行，双方言复用按品牌和题集编号的 100 条分块读取。缓存键加入最新题集编号并升级结果版本。按 30/120 条合成样本核对，SQLite 和 PostgreSQL 冷读均为 11/13 次 SQL，命中为 1 次。SQLite 的运行左连接走主键，PostgreSQL 在该范围走 `monitoring_run_brand_recent_idx`。缓存测试覆盖 memory 与 Redis 共享命中、分析修订和 Redis 不可用回源。
