# M0-135 观察计划

2026-11-24。 [Issue #135](https://github.com/Godyu97/geo-pro/issues/135) · [视觉验收清单](../08-验收场景与样例.md#ui-visual-checks) · [S-M1-06](../specs/M1.md#s-m1-06)

品牌负责人打开观察计划后，应能先看到当前任务和下一步。还没有观察时，下一步是保存观察，不改写冻结题集，也不创建采样运行。还没有检查点，或最近一次尚未到期时，下一步是记录检查点。未到期只记进度，完整结论留空。窗口到期但可比题低于 80% 时，下一步是查看排除题，不写成正式结论。窗口到期且达到门槛时，下一步是查看检查点记录，这只是正式对比，不是因果试验。读取失败时保留标题，不显示题集编号和品牌名称，并用键盘重新载入。

基线 `4f6b54cf1afff0a4d6589d8fb387c14a6ee6363b` 在隔离 Chrome 中文 375 像素复现。页面没有「下一步是保存观察」。空说明排在建立表单之后，首屏停在表单里的保存按钮。

- `/dashboard/reports/observations` 留在工作台唯一的 `main#main-content` 内。标题是观察计划。任务说明放在同一内容区。相关入口换行，包含返回复测与报告。
- 还没有观察时，主要动作是保存观察，只出现一次。表单字段留在内容区。64 字冻结题集编号在标题内换行。
- 还没有检查点，或最近一次模式是进度时，主要动作是请求正式结论，只出现一次。未到期写入的检查点模式是 `progress`，结论为空，状态保持 `observing`。
- 最近一次是探索时，主要动作是查看排除题。排除题原样保留。请求正式结论留在记录表单里一次，不作为页首动作。
- 最近一次是正式时，主要动作是查看检查点记录。页面分支写明这不是因果试验。
- 读取失败时标题仍是观察计划，提示可重试，主要动作是重新载入当前地址。不显示题集编号和品牌名称。其他账号打开同一品牌地址仍看不到这些内容，主要动作是去建档。
