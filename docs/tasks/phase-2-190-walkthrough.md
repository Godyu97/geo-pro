## 本轮改动与门禁

- 证据页提交后打开本次生成或合并的任务。任务带品牌、问题簇和页面进入 Brief，提交时校验任务归属。创建及编辑 Brief 可勾选已批准事实，取消勾选在重新打开后生效。内容计划中的证据链接指向原回答详情。
- 发布核验后的复测入口携带品牌，报告表单从同品牌记录中选中该发布。报告仍按实际样本与窗口规则判定可比性。
- 本人品牌导出供开发环境和隔离验收使用，生成及下载沿用会话和归属校验。受影响 API 的浏览器来源校验优先采用应用配置的来源。
- `pnpm env:check` 15 项通过。lint、typecheck、build、多语言消息及基础测试通过，lint 有 2 条既有未使用变量告警。页面抓取与来源校验、数据导出、监测、证据、优化、内容和报告专项通过。隔离 SQLite/PostgreSQL 的生产模式导出 HTTP 验证通过。隔离 Chrome 通过 M0 主流程、优化入口、团队权限、行业题包、观察计划及经营助理回归。本人导出 8 项双语 Chrome 用例通过。
