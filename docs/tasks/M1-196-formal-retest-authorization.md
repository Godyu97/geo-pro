# Issue #196 正式观察与干预批次品牌授权

2026-11-27。 [Issue #196](https://github.com/Godyu97/geo-pro/issues/196) · [S-M1-06](../specs/M1.md#s-m1-06) · [S-M1-08](../specs/M1.md#s-m1-08) · [指标与证据合同 §7](../07-指标与证据合同.md)

报告总览按当前品牌打开观察计划与干预批次。两个子页的返回链接、表单成功和校验失败后的跳转保留 `brandId`。显式品牌在工作台开始流式加载前核验，页面本身、Server Actions 和 API 也校验品牌授权。

- 权限沿用 group 品牌动作。获准 `member` 可登记观察、检查点、混杂因素、对照页、停止原因、干预批次和页面核验。 `read_only` 可查看，页面隐藏写操作，API 拒绝写入并返回 403。未获准或撤销授权的会话返回 404。
- 按记录 ID 访问时，先通过主键取品牌，再校验当前操作者对该品牌的动作授权。表单里的品牌与记录所属品牌必须一致。后续读取和写入沿用已授权品牌的归属者键，组内成员共用同一份历史。列表继续按归属者与品牌批量读取子记录。
- 隔离回归覆盖已经生效的组内干预落在 14 日基线内时，检查点保留 `baseline_intervention` 并进入探索。停止观察保留已写的检查点和结论。本次沿用现有表结构。
