## 做了什么

- 事实页和题集页在 `fixture` 或 `mock` 入口下打开。正式入口仍然不因这个开关收集真实材料。
- 现有录入页不重做。mock 模式增加一个按钮，经原有事实命令写入并批准一条带 `[FUNCTIONAL-MOCK]` 的事实，再经原有冻结命令保存三道非品牌确认题。
- 重复点击会复用已经写过的 mock 事实和 mock 题集。

## Mock 边界

事实出处、摘录和题目都是仓库内合成文本。没有真实品牌材料，没有客户问题，没有搜索量。来源类型是 `material`，不是外部抓取。
