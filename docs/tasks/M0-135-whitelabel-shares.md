# #135 白标分享页

2026-11-25。品牌负责人从「账户设置 → 白标分享」进入后，可在页首开始登记、查看历史、前往品牌资料或重新载入。分享卡片展示访问状态、原始轨道、整数样本量、结论等级、UTC 到期时间及访问记录。

本轮覆盖 [全站视觉验收](../08-验收场景与样例.md#ui-visual-checks) 的入口、状态反馈、双语响应式和键盘交互，以及 [S-M2-03](../specs/M2.md#s-m2-03) 中 AC-M2-03-2 的负责人预览路径。现有分享仅允许登记账号预览，登记时记录三个报告字段。客户下载、报告快照绑定和正式多品牌场景仍待核验。

## 基线与实现

- 基线 `71c8bf911433394020f4335e1308a9a5df83d0e7` 使用隔离库的无品牌账号，经账户设置打开中文 375 像素页面。标题可见，缺少前往品牌资料的操作。基线截图为 `.cache/issue-135/shares/baseline-375.png`。源码按撤销标志单独判断，因此已到期的记录也显示可查看。
- 页首操作复用共享按钮，登记可跳转并聚焦品牌字段，历史可聚焦清单标题。读取失败时保留标题，可用键盘重新载入。分享卡片复用徽标及白色面板，长品牌名称和轨道可换行。展示时间按界面语言格式化为 UTC，原始时间戳保留在 `time` 元素中。
- 到期由服务端时间判定，打开页面后按最近的到期点刷新状态。预览继续走受控读取 API，并按回执显示轨道、样本量和等级。撤销先说明对预览与历史的影响，然后由用户确认。在途锁拦截本次操作的重复提交，状态消息随界面语言更新。
- 首次隔离浏览器走查时，同源 GET 预览未发送 `Origin`，因现有来源校验返回 403。页面改用同一资源的 POST 发起带访问记录的预览，复用已有会话、来源及品牌归属检查，兼容已有 GET 调用。

## 验收证据

- `zh-CN` 与 `en` 各在 375、768、1440 像素核对无品牌、可登记和已有分享。主内容区唯一，页首操作完整位于视口，页面无横向溢出。长品牌名在卡片内换行，原生品牌下拉框收起时会截断长选项。双语 375 像素另核对加载、读取失败与键盘恢复。
- 键盘可到达登记字段和历史标题。负样本量、已过期时间和效果保证提交被拒绝。登记在途时再次按 Enter 只发一笔请求。注入 503 可原位重试，输入和焦点保留，切换英文后提示更新。
- 预览回执与数据库登记均为 `official_api`、`1234`、`exploratory`。页面切换语言后保留这三个值和原始到期时间。成功预览新增一条登记账号的访问记录。缺少来源或来源不可信返回 403，未登录返回 401，另一账号的预览、撤销和登记返回 404。
- 两种语言的撤销确认先聚焦取消。Escape 返回触发按钮且无写入。撤销遇到 503 可原位重试，成功后焦点回到分享标题，预览请求返回 404，原访问记录逐项一致。另登记一条 8 秒后到期、样本量为 0 的分享，开着页面可观察到从可查看转为已到期，预览请求返回 404，未增加访问记录。品牌归档后可查看两条历史，新增登记返回 404。
