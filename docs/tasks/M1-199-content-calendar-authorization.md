# Issue #199 内容日历与维护任务品牌授权

2026-11-27。[Issue #199](https://github.com/Godyu97/geo-pro/issues/199) · [多渠道内容维护](../specs/M1.md#s-m1-05) · [团队品牌权限](../specs/M1.md#s-m1-08)

## 交付

内容日历按登录人的品牌授权读取。品牌负责人和获准 `member` 可以检查到期事实，按渠道保存已核验或受阻状态。`read_only` 和只有平台管理员身份的账号可查看日历，写入返回 HTTP 403。无权账号访问日历页面和接口返回 HTTP 404。事实页选中事实版本后，可以打开带同一事实筛选的日历。提交和重载会保留该筛选。

服务端在写入事务内核验当前授权，以品牌原有数据归属查询并写入任务。到期扫描在同一事务完成，重复检查沿用开放任务。组内协作者可从日历页首跳到受影响页面表。原品牌负责人的发布详情仍使用既有入口。保存维护状态只更新内部任务和渠道记录。

## 剩余验收

开发环境中，持久化 `member` 可访问的两个品牌均有 0 条发布记录和 0 条维护任务。需要在其获准品牌中有一条来自真实发布及符合条件事实的开放维护任务，再用同一账号打开日历核对任务和渠道状态。开放任务与渠道保存目前只有隔离回归证据。本轮没有外部发布、删除或调用费用。Issue 保持开放并标为阻塞，M1 阶段验收仍按原计划跟踪。
