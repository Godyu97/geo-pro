## 验收与实际检查

官网专项 `pnpm test:e2e tests/e2e/marketing.spec.ts` 已通过：11 个 Chrome 场景，41.8 秒。覆盖入口分流、两种语言与三种宽度、键盘/焦点、伪造/过期身份、并发身份与语言 SSR 隔离、未配置/故障及恢复；切换无 API 写入，继续工作台保持本人身份。已查看英文 375 和中文 1440 的完整页面截图。全量集成复核 33 项全部通过，1.9 分钟；截图保存在忽略的 `test-results/`。

首次全量回归 32 项通过、1 项失败：既有英文 UI 注册场景在连续临时账号请求后收到生产限流 429。核对本机 Better Auth 实现，注册限流保留默认 10 秒 / 3 次；仅扩充 `tests/e2e/auth-helpers.ts` 并在 `i18n.spec.ts` 的入口往返场景使用：收到明确 429 才按响应中的有界等待时间再次点击，未知失败不重放，成功仍须 200。生产认证选项和验收断言未放宽。修正后全量通过，故障副本的预期异常日志不代表检查失败。
