# T-M0-02 品牌事实与补证验收

2026-11-18 · [Issue #22](https://github.com/Godyu97/geo-pro/issues/22) · [S-M0-02](../specs/M0.md#s-m0-02)

## 使用

在已建档品牌的详情页进入「事实与材料」。负责人可直接填写事实，也可粘贴最多 20,000 字，按行预览或选中原文手工拆卡。保存原文修订会生成新版本，已关联的候选仍指向原选段。候选缺来源、许可或有效期时可保存并补证。提交待确认后须由本人逐条核对并批准。

修改已确认的主张从原版本选择「录入新版本」。同一事实系列中主张有变化时，待确认版本展示上一批准版及其影响入口。明确选择后可在批准新版时撤销旧版。有效截止日按 UTC 计算，含当日。价格从批准日起 30 天提醒复核，其他长期事实为 180 天。复核提醒与到期分别计算。

## 存储与使用资格

- `brand_fact_paste` 保存原文及前次修订，原文列表按创建时间及 ID 分页。`brand_fact_version` 绑定品牌实体版本及可选原文选段，按事实族的关联键和版本号取回历史。来源、批准人和批准时间随批准版保存。
- `brand_fact_use` 以品牌、事实版本和使用版本为键。关联版本可从任一侧读取。正式交付调用方须通过 `withEligibleFacts` 在与撤销共用的负责人事务中核验所有引用，并在同一事务完成需要资格的数据库写入。公开投影只交付已许可的主张及两个版本标识。过期或撤销使未完成的审阅或交付失效，线上内容显示待维护，历史引用仍可核对。
- 双方言使用同一参数化 DAO，并保留各自的 Schema、迁移和全量 DDL。事实详情工作台在 2 条和增加 500 条合成版本后均使用 7 条 SQL，SQLite3 约 2.13 / 3.35 ms，PostgreSQL 约 6.21 / 8.23 ms。双方言最近版本分页均使用 `fact_version_recent_idx`。下游按批次核验最多 100 个版本。删除预览分别计数事实版本和原文修订，冻结即时拒绝普通访问，到期清除覆盖事实、依赖和原文。
- 页面和接口复用 `GEO_BRANDS_FIXTURE=1` 的回环验收边界。接入真实资料需要 [试点开放 #21](https://github.com/Godyu97/geo-pro/issues/21)。本人下载仍按 B05 已披露的范围。正式 Brief、稿件和交付消费者接入时应重跑资格、撤销和影响场景。
