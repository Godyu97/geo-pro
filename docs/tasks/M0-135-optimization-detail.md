# M0-135 优化任务详情

2026-11-24｜[#135](https://github.com/Godyu97/geo-pro/issues/135) · [全站视觉验收清单](../08-验收场景与样例.md#ui-visual-checks) · [S-M0-08](../specs/M0.md#s-m0-08)

品牌负责人从优化任务列表打开详情，可读目标页、发现与依据和页面检查记录，并从标题区直接到达状态表单。更新被拒绝时可看到本地化提示、保留输入并重试。保存后可在状态标签和已保存的更新详情中回读结果。

## 复现与交付

- 基线 `2898441b96fcc94f76f41671282c1a5cdc4a0429` 在迁移后的临时 PostgreSQL 上，用合成受限页面生成任务。在英文 Chrome 375 × 900 视口选择「已记录修改」并用 Enter 提交，未填完成说明。服务端拒绝，页面缺少可读反馈，新增的告警断言失败。
- `/dashboard/optimization/[taskId]` 复用工作台主题，主操作定位到状态表单。返回任务列表保留品牌范围。目标 URL、发现原文和页面检查记录可以在白色面板内换行，检查状态用当前界面语言显示。
- 状态表单使用既有服务端会话、输入校验、任务归属和更新命令。处理中的表单暂时禁用。失败保留输入，保存后显示反馈并回读完成说明、驳回理由和改序记录。缺失与其他账号的详情共用同一个提示和返回动作，留在工作台的单个主要内容区。

## 开发环境

在回环 `127.0.0.1:3125` 通过 `pnpm start --hostname 127.0.0.1 --port 3125` 启动生产构建，使用配置的开发 PostgreSQL 和长期邮件 Mock。Chrome 注册临时账号后，查询随机任务 ID 的详情接口得到 404。两种语言在 375 像素下均出现任务不可用提示，页面只有一个主要内容地标，没有表单和横向溢出。返回按钮有可见焦点，可用 Enter 回到任务列表。临时账号已删除并回读确认。

## 隔离浏览器验收

使用 `testDatabase("postgresql")` 创建并迁移回环临时库，启用 memory 缓存和长期邮件 Mock，关闭公开页外部请求。使用合成账号、品牌与受限页记录。运行 `pnpm test:e2e tests/e2e/optimization-entry.spec.ts tests/e2e/m0-flow.spec.ts`，两项通过，临时账号和库已清理。首次改动后的回归发现 React 表单自动重置了被拒绝的状态选项。显式提交后完整重跑通过。

| 场景 | 实际结果 |
| --- | --- |
| 详情、页面检查与键盘 | 两种语言各在 375、768、1440 像素下保留品牌返回入口，长目标 URL、发现中的证据和页面检查 URL 可折行。单一主要内容地标，无横向溢出。从返回入口按 Tab 到主操作并显示焦点，Enter 跳到表单，下一次 Tab 到状态选择 |
| 拒绝、修正与回读 | 375 像素下中文提交缺完成说明，英文提交缺驳回理由。两次均显示告警，PostgreSQL 回读与提交前一致，状态和改序输入保留。中文草稿切到英文再切回中文，输入和反馈保留。补全后用 Enter 保存，详情状态更新，数据库和刷新后页面均可回读说明及改序 |
