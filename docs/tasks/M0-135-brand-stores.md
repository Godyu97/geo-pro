# Issue #135 门店服务范围

2026-11-25。 [Issue #135](https://github.com/Godyu97/geo-pro/issues/135) · [全站视觉验收](../08-验收场景与样例.md#ui-visual-checks) · [S-M2-06 / AC-M2-06-3](../specs/M2.md#s-m2-06) · [本地观察](M0-135-local-observations.md)

品牌负责人从品牌资料的「登记门店范围」进入 `/dashboard/brands/stores` 后，先看到当前状态下的下一步。没有活跃品牌时，页首动作是去建档。已有活跃品牌但还没有门店时，动作是填写门店名称和只属于这家店的服务范围。已有门店时，动作是查看各店范围，并只按本店已保存的范围核对。把另一家门店的范围写入核对会被拒绝，不会留下核对记录。读取失败时保留标题，隐藏品牌名称和门店范围，并用键盘重新载入。

## 范围

- 页首按无品牌、空门店和已有门店给出一个主要动作，并保留相关入口。
- 两家门店的服务范围仍分别保存。核对只接受本店已保存的范围，跨店范围不写入 `store_fact_use`。列表查询仍是一条门店查询。
- 路由补了加载骨架。读取失败使用原生重新载入链接，并显示追踪编号。

## 验收

隔离浏览器使用合成品牌和两家合成门店。名称没有空格。临时账号已清理。

| 场景 | 实际结果 |
| --- | --- |
| 无品牌 | `zh-CN` 与 `en` 在 375、768、1440 像素只有一个 `main`。顶栏分区是品牌资料或 `Brand information`。页首可见任务说明，「去建档」或 `Open brands` 在 375 像素位于视口内，页面没有品牌名称，也没有门店名称输入，且无横向溢出。中文 375 像素从品牌资料用键盘进入该入口，再从「去建档」回到品牌资料。 |
| 已有品牌、尚无门店 | 两种语言和三种宽度都显示长品牌名称和空门店说明。375 像素「填写门店」或 `Enter a store` 位于视口内，键盘激活后焦点落在门店名称。页面无横向溢出。中文 375 像素从品牌资料用键盘再次进入。 |
| 无效名称 | 中文 375 像素把门店名称留成空白字符。页面显示请检查品牌、门店名称和服务范围，已输入内容保留，没有发出保存请求。 |
| 慢速保存 | 中文 375 像素保存长名称的西湖店，服务范围是西湖。按钮显示「正在保存…」且 `aria-disabled="true"`，第二次 Enter 不再发出请求。保存后可见西湖的服务范围。 |
| 已有两家门店 | 两种语言和三种宽度都显示长品牌名称、西湖店和滨江店。西湖卡片只显示西湖，滨江卡片只显示滨江。375 像素「查看门店」或 `View stores` 位于视口内，键盘激活后焦点落在门店列表。页面无横向溢出。 |
| 跨店核对 | 中文 375 像素在西湖店的核对里填写滨江。页面显示不能把其他门店的范围写入这家门店，已输入内容保留。数据库没有核对记录。 |
| 本店核对 | 改回西湖后保存。两种语言和三种宽度下，西湖卡片显示本店核对和「只使用本店范围」，滨江卡片仍没有核对。数据库两条门店范围分别是西湖和滨江，唯一核对记录的范围是西湖，`used_other_store` 是 0。 |
| 其他账号 | 英文 375 像素打开同一入口，看到自己的无品牌说明，看不到原品牌名称、两家门店或两个服务范围。 |
| 读取失败 | 中英文 375 像素先看到加载骨架，再看到安全错误和「重新载入」。失败页不显示品牌名称、门店名称、服务范围和内部异常。清除故障后用键盘重新载入，恢复同一品牌、两家门店和西湖核对。 |
