# #135 套餐权益页

2026-11-25。品牌负责人从「账户设置 → 套餐权益」进入后，在页首可以开始登记、查看权益版本、前往品牌资料或重新载入。每个版本显示对应的监测、内容及人工额度和用量，也可展开该版本的用量或调整表单。

本轮覆盖 [全站视觉验收](../08-验收场景与样例.md#ui-visual-checks) 的入口、双语响应式、键盘与状态反馈，以及 [S-M2-03](../specs/M2.md#s-m2-03) 的本地权益登记和历史用量约束。三个编号 AC 分别跟踪委托、白标报告来源和报价订单。本轮范围为套餐权益入口。

## 基线与实现

- 基线 `3452866befdc3e049ae6cf45f606b94be19df4da` 的隔离浏览器使用无品牌账号，从账户设置打开中文 375 像素套餐权益页。标题可见，期望的「前往品牌资料」入口缺失。基线截图为 `.cache/issue-135/entitlements/baseline-375.png`。
- 页首复用共享按钮。登记入口可聚焦品牌字段，历史入口可聚焦版本清单标题。加载复用骨架，读取失败保留标题并可重新载入。长品牌名在版本卡片内换行。原生品牌下拉框收起时会截断长选项。
- 卡片按试用或报价分别显示版本，整数直接取保存值。记录时间按界面语言显示 UTC，机器可读时间保留原始时间戳。用量与调整表单默认收起，可用键盘分别打开。写入反馈按当前界面语言显示，在途拦截同一表单的再次提交。

## 验收证据

- `zh-CN` 与 `en` 各在 375、768、1440 像素核对无品牌、可登记和已有版本。工作台位置可辨认，主内容区唯一，页首动作完整位于视口，页面无横向溢出。归档与读取恢复另在双语 375 像素走查。
- 键盘到达品牌字段、版本清单和每版用量或调整控件。负数额度和 0 用量返回 400；登记请求挂起时再次按 Enter 只发一笔请求。登记和用量分别注入 503，输入及提交焦点保留，原位重试成功。登记失败后的语言切换同时更新提示并保留输入。
- 试用第 1 版回读为监测额度 1200、内容额度 20、监测用量 3。调整后试用第 2 版监测额度为 1100、用量为 0，第 1 版原行和用量记录逐项一致。另登记报价第 1 版，内容额度 30。三版均显示未收款，含收款声明的登记返回 400。切换语言保留整数和原始时间戳。
- 另一账号读取指定版本、登记、调整及追加用量均返回 404，页面无权益卡片。品牌归档后仍可查看原版本，卡片沿用品牌编号，新增登记返回 404。读取失败隐藏表单、记录和内部异常，键盘重新载入可恢复。
- 隔离与开发数据库使用各自的临时测试账号和合成品牌。结束后回读账号、品牌及版本、权益及用量已清理。
