# #135 外部连接页

2026-11-25。品牌负责人从「账户设置 → 外部连接」进入后，可以从页首登记连接、查看已登记的能力、打开已撤销连接的历史，或在读取失败时重新载入。无可登记品牌时，页首提供前往品牌资料的入口。

本轮对应 [全站视觉验收](../08-验收场景与样例.md#ui-visual-checks) 的页面覆盖、状态反馈、双语响应式与键盘操作，并核对 [S-M2-02](../specs/M2.md#s-m2-02) 的 AC-M2-02-1、AC-M2-02-2 本地路径。外部结果为合成夹具选择的状态。

## 实现与复用

- 页首用共享按钮区分当前主要动作和返回入口。登记链接聚焦品牌字段，查看链接聚焦连接标题。连接能力、状态、历史和可用操作保留在同一张卡片，长名称和幂等键可换行。
- 登记和动作表单在成功后清空，失败后保留输入。反馈按当前界面语言显示。撤销使用共享确认弹窗，说明拒绝新动作及历史保留的影响。读取失败时保留标题及重新载入入口，隐藏记录、表单和内部错误。
- 基线 `1d7ec33e10c70e07aa35b8f13c6f8689f3b5d9a7` 在隔离 Chrome 中文 375 像素实测缺少页首「开始登记」链接。截图保存在本地 `.cache/issue-135/external-connections/baseline-375.png`。

## 验收证据

- `zh-CN` 和 `en` 各在 375、768、1440 像素检查有品牌无连接、待核验连接、仅有撤销记录和无品牌四种状态。账户设置位置可见，主内容区唯一，页首操作完整位于视口，页面无横向溢出。长品牌、连接名和动作键在卡片内换行。原生品牌下拉框收起时会截断长选项。
- 中文窄屏按 Enter 从页首聚焦品牌字段。登记返回 503 时保留输入和按钮焦点，切换英文后输入保留、提示更新。再次用键盘登记成功后表单清空，数据库回读一条待核验连接，只有草稿权限。键盘标为已核验后，状态更新，焦点返回连接标题。
- 草稿权限连接即使填入公开地址回执和时间，仍显示未发布和人工后续。记录未写入回执或公开生效时间，公开核验和干预生效均显示「否」。另一条本地连接使用合成的未知结果，键盘对账后保留同一动作编号。重复提交同一幂等键后仍为一条记录，状态和时间原样回读。
- 中英文撤销弹窗先聚焦取消，Escape 关闭后回到触发按钮，数据库无写入。确认返回 503 时原状态和焦点保留，重试成功后焦点回到连接标题。撤销后提交新动作返回 409，既有动作逐字段回读一致。
- 双语窄屏核对加载、读取故障和键盘恢复。故障发生在连接读取后、品牌标签返回前，页面隐藏已读记录和内部异常。第二账号登记、更新、提交动作和对账均返回 404。隔离库与配置的回环开发库使用临时测试账号和合成品牌，按账号清理后回读确认没有残留的账号、品牌、版本、连接及动作。
- 首轮隔离浏览器用例等待 `response.json()` 超时。故障现场保留了界面中的人工后续和数据库中的拒绝记录。改用 HTTP 状态、页面回执和持久化结果作为断言后复跑。最终版整组复跑在通知端点结束前收到 SIGTERM，临时应用和库已清理，随后拆分命令复跑。首次拆分运行中，既有通知端点用例期望的 503 注入未生效，实际返回撤销成功。弹窗截图关闭动画采样，以保存稳定状态。
