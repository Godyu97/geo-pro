## 实现与关键决定

- `src/lib/i18n/` 提供白名单解析、JSON 消息、请求级复用、Server Action 和 Intl；`zh-CN` / `en` 不引入运行期翻译库。默认中文，无已存选择时匹配受支持的浏览器偏好；显式 Cookie 优先，无效 Cookie 回退中文。
- 保留现有 URL，语言切换不增加历史记录、不丢弃查询/片段、不提交表单。Cookie 保存一年，HttpOnly / SameSite=Lax，生产环境 Secure；不增加偏好表或 Schema。
- RootLayout 与 Metadata 在服务端解析同一 locale；客户端只接收当前语言的公共及当前页面消息。Proxy 禁止 HTML/RSC 公共缓存，原认证和机器 API 路径不变。
- 官网、登录页、工作台和导航同步提供英文；表单校验保存稳定码，切换后已有错误跟随翻译。未知服务错误采用安全消息，429 映射为限流提示。姓名按 Unicode 码点限制，IME 组合回车不提交。
- 侧栏支持中英名称、关闭按钮和关闭后的焦点恢复；语言选择支持键盘且切换保留焦点。错误正文采用 AA 对比度颜色，长名称和英文可换行。
- 登录前深链接仅接受现有本地 `/dashboard` 返回目标，保留查询参数；外部/未知路径回退工作台。服务端 `auth.api.getSession` 仍为会话权威。
- 常规错误/404/加载状态使用请求语言。根布局自身失败时，独立 `global-error.tsx` 同时提供完整中英文，英文片段标记 `lang=en`；此时不依赖已失效的 Provider。返回首页进行整页恢复，再从 Cookie 解析原偏好。

主要文件：`src/app/` 的现有页面/布局及新增边界、`src/proxy.ts`、`src/components/layout/`、适用的 `ui/form.tsx` / `ui/sidebar.tsx` / `ui/sheet.tsx`、`src/lib/auth/validation.ts` / `return-to.ts` / `session.ts`、`src/lib/i18n/`。

验证入口：`scripts/check-i18n.mjs`、`tests/i18n/core.test.mjs`、`playwright.config.ts`、`tests/e2e/i18n.spec.ts`、`scripts/serve-i18n-fixture.mjs`。新增开发依赖 `@playwright/test@1.65.1` 用于真实浏览器验收；不增加运行期依赖。忽略生成的测试缓存/报告，避免质量门禁扫描生成文件。
