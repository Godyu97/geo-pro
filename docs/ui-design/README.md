## 共享主题

颜色、圆角和焦点定义在 `src/app/globals.css` 的 `:root`。按钮、输入、卡片、表格、弹窗和侧栏从这些变量取值，不另写一套颜色。

- 基底 `--background` 为浅蓝紫，表面 `--card` 和侧栏 `--sidebar` 为白色。主操作、当前强调和焦点使用紫蓝 `--primary` / `--ring`。侧栏选中态使用浅色 `--sidebar-accent`。
- 官网和账号页使用 `visual-canvas` 铺浅色光晕。工作台内容区保持基底色，顶栏和卡片使用白色表面。
- 工作台顶栏显示当前分区。侧栏在总览、每周行动、维护、账户设置，以及品牌、监测、优化、内容和报告路径上标出当前位置。
- 工作台内容区只有一个 `main#main-content`。侧栏所在区域保持为布局容器，业务页不再套第二层 `main`。
- 主按钮悬停保持白色文字可读。致命错误页在样式表不可用时使用同一组颜色。

## 视觉与组件

- 浅色基底配白色和浅蓝灰表面，采用深色文字和紫蓝主色。主色强调主要操作、当前导航和关键交互。状态使用相应的文字、图标与颜色组合，文字对比度沿用产品可访问性基线。
- 标题、常用正文、辅助信息和数字有稳定的层级。间距、圆角、边线、阴影和焦点样式从共享主题取值。按钮、表单、标签页、卡片、表格、侧栏、弹窗和状态反馈复用仓库已有组件及适用变体。
- 官网可使用柔和渐变和品牌插画，工作台优先保证数据、操作和下钻可读。凡涉及监测指标、趋势、平台覆盖、客户评价或效果的展示，依据真实数据和已核验能力；无数据时呈现相应空态，演示内容使用既有演示标识。

## 页面设计与后续维护

Agent 根据任务自行决定布局、组件组合、图表形式、插画、字号和微交互。新增页和改版页继承共享主题、导航与交互状态，并沿用页面功能、权限、指标和双语言合同。可复用的新变体放回现有组件或主题入口，多个页面使用同一语义。

官网与账号页清楚呈现主路径和表单反馈。工作台保持当前品牌、导航位置、页面标题、筛选范围和主要动作可辨识。报告入口、内容入口、证据概览、回答列表和品牌入口把标题、任务说明和相关入口放在同一内容区，长标签换行，空列表使用虚线表面。没有品牌时，内容入口的主要动作是前往品牌，证据概览和回答列表的主要动作是前往品牌资料，品牌入口的主要动作是建立品牌或继续草稿。已有活跃品牌时，品牌入口的主要动作是查看品牌。有可计算样本时，证据概览的主要动作是查看回答列表，回答列表中每条的主要动作是查看证据。采样计划的页首可以打开站内提醒。质量提醒先显示原因、窗口和发生记录，确认是待处理提醒的主要动作，长窗口编号在卡片内换行。竞品与来源从 AI 回答进入，页首显示品牌和任务，主要动作是保存竞品集。份额表限制在组件内滚动。没有已记录提及时不显示无序说明；有无序提及时写明不排名。找不到版本时保留标题，并回到当前品牌。长名称和引用地址在卡片内换行。品牌详情的标题是品牌名称，任务说明和实体版本放在同一内容区，主要动作是当前监测下一步；历史版本的主要动作是查看当前版本。读取失败时不显示品牌正文，恢复动作是重新载入。内容 Brief 的标题是标题候选。缺项时主要动作是补齐第一项，补证已齐时是确认 Brief，已确认后才是生成草稿。长主页面在内容区内换行。读取失败时不显示标题候选和主页面，恢复动作是重新载入。内容批次的标题是批次详情。生成中的主要动作是暂停，已暂停是继续，有失败项是仅重试失败项，全部成功后是查看稿件。不适用的控制不出现。长批次编号和账本快照在内容区内换行。读取失败时不显示单元和账本，恢复动作是重新载入。内容稿件的标题是稿件详情。待审草稿的主要动作是提交审核，审核中是批准，已拒绝或批准失效后可以再次提交。当前批准仍有效时，主要动作是运行预检。拒绝留在页面后部，且只出现一次。长标题在内容区内换行。读取失败时不显示标题、正文和批准指纹，恢复动作是重新载入。发布回填的标题是发布核验详情。尚未核验时主要动作是运行公开核验，草稿箱或页面受限时是提交人工证据。长网址和稿名在内容区内换行。登录墙核验不写生效时间。读取失败时不显示网址、稿名和申报时间，恢复动作是重新载入。列表、详情、表单与分析页的密度可随任务调整。窄屏适配导航、按钮和内容回流，宽表格有可操作的局部滚动。状态说明和图表含义可通过文本读取。

实施时先核对 `src/app/globals.css`、`src/components/ui/` 和 `src/components/layout/` 中的共享主题和组件，随后按现有路由覆盖页面。变更共用视觉规则时同步维护此页和对应验收记录。验收见 [全站视觉验收清单](../08-验收场景与样例.md#ui-visual-checks)。
