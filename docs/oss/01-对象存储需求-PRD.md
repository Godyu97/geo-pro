# 对象存储需求（PRD）

> 版本：1.0｜2026-11-21｜范围：GeoPro 用户业务文件的对象存储｜状态：需求合同，代码未接入。

<a id="oss-prd"></a>

本文件定义 GeoPro 存放用户业务文件的对象存储能力。它服务现有品牌资料、内容交付、发布核验、报告和本人导出，不新增第 27 项产品功能，不改变 [公共 SPEC](../04-产品功能规格-SPEC.md) 的状态轴、指标口径或 26 项需求计数。业务语义仍以 [产品 PRD](../02-产品需求文档-PRD.md)、分级 SPEC 和 [指标与证据合同](../07-指标与证据合同.md) 为准。精确行为见 [对象存储 SPEC](02-对象存储功能规格-SPEC.md)。

## 1. 要解决的问题

当前这些用户文件还没有独立的对象存储：

| 用户文件 | 现在的落点 | 用户可观察的缺口 |
| --- | --- | --- |
| 内容授权图片 | `content_asset.content_ref` 只保存最长 2000 字的引用 | 工作台不能把图片字节交给品牌负责人保管，也无法按权利状态收回下载 |
| 内部资料附件 | 产品要求原附件不得进入公开包 | 没有与公开素材分开的私有字节存储 |
| 交付包 | `content_delivery_package.files_json` 把 Markdown、HTML、清单等正文放进数据库 | 包变大后与业务元数据挤在同一行，旧包仍须可追溯 |
| 报告快照 | `report_snapshot` 的 `html_bytes` / `json_bytes` | 纠错后的新快照必须留下旧文件，正文不适合继续堆在行内 |
| 本人数据导出 | 下载时按记录重读数据库 | 导出文件需要短时、可撤销的下载，不能变成匿名地址 |
| 人工核验证据 | `screenshot_ref` 只保存引用字符串 | 受限页面的截图应作为私有证据保存，不能显示成匿名公开访问成功 |
| 资料原件（M1） | 导入规则已限制 10MB / 50,000 字 / 每批 10 个文件 | 原件字节还没有可按版本引用的存放位置 |

对象存储补上的是字节的存放、校验、授权下载和删除。事实是否批准、稿件是否可发布、报告结论是否改善，仍由原业务模块决定。

## 2. 用户与场景

操作者沿用产品角色：M0 品牌负责人管理自己品牌的文件；M1 起，运营、分析者和只读成员是否能读内部附件或导出，服从品牌授权和独立导出授权。对象键、预签名 URL 和存储账号都不能代替会话与资源归属。

| 场景 | 操作者 | 成功时用户看到的结果 |
| --- | --- | --- |
| 上传内部附件 | 品牌负责人 | 附件只出现在品牌内部资料中，正式交付包没有该文件 |
| 上传授权图片 | 品牌负责人或内容运营 | 图片带来源、用途和权利声明；未审核或归属未确认的图片不能进入正式包 |
| 导出交付包 | 审核者 | 新包写入对象存储并给出清单和指纹；标题、图片或事实版本变化后，旧包仍可打开并标为勿再使用 |
| 下载报告 | 品牌负责人 | HTML 与 JSON 来自同一快照；再次出报告不改写旧文件 |
| 下载本人导出 | 账号本人 | 每次下载重新校验会话、范围和归属；失权、重生成或删除后，旧地址失效 |
| 提交人工核验证据 | 发布者 | 截图作为私有证据关联该次核验，状态保持 `verified_manual` |
| 冻结或清除品牌 | 品牌负责人 | 冻结后不能再上传或普通下载；清除到期后删除对象字节，审计记录不含客户正文 |
| 撤销素材或成员授权 | 负责人 / 被撤销成员 | 新的下载被拒绝；已经导出的历史包保留可追溯记录 |

<a id="oss-compatibility"></a>

## 3. 兼容性与接入形态

本仓库的接入形态固定为 **Next.js 服务端模块**。浏览器、Client Component 和 `NEXT_PUBLIC_*` 不持有存储密钥。

对象访问统一使用 AWS SDK v3 的 S3 客户端：

- 读写、列举范围约束、删除使用 `@aws-sdk/client-s3`。
- 发给浏览器的短时下载链接使用官方配套 `@aws-sdk/s3-request-presigner`。
- 本地 SeaweedFS 与阿里云 OSS 共用这一套客户端和同一组环境变量名。
- 生产切到阿里云时，使用阿里云 OSS 的 **S3 兼容 API**（SigV4）。替换 Endpoint、Region、Bucket 和密钥，并把路径风格开关关掉。
- 应用不维护第二套阿里云私有协议客户端，也不把 SeaweedFS 文件浏览入口的基本认证当作应用凭据。

两条部署都要满足同一行为：

| 部署 | 端点含义 | 路径风格 |
| --- | --- | --- |
| 本地 SeaweedFS 4.54 | 宿主机进程使用回环 S3；浏览器链接使用签名时指定的局域网或将来的公网主机 | 开启 `forcePathStyle` |
| 阿里云 OSS | Endpoint、Region、Bucket 使用 OSS 控制台给出的 S3 兼容值；服务端与浏览器若都能访问同一公网 HTTPS 端点，两个端点变量可以相同 | 关闭 `forcePathStyle`，使用虚拟主机风格 |

预签名 URL 在签名时写入协议、主机和端口。签名之后应用不再改写主机或端口。本地公网入口尚未开通时，不得用出口公网地址签发浏览器链接。2026-11-21 的现场事实是：宿主机 S3 为 `127.0.0.1:8333`，局域网地址为 DHCP 的 `192.168.100.157:8333`，出口 `45.12.88.122` 的 8333/8888 从外部探测不可达。路由器完成 `8333/tcp` 与 `8888/tcp` 转发并且蜂窝网络确认 S3 返回 403、文件入口返回 401 之后，才允许把浏览器端点改成该公网地址。

<a id="oss-objects"></a>

## 4. 对象类别

一个桶，用键前缀区分对象。类别决定谁能下载、能否进入正式交付包、以及字节是否允许覆盖。

| 类别 | 服务的产品对象 | 可见性 | 写入后 |
| --- | --- | --- | --- |
| `internal-material` | 事实与资料的内部附件 | 仅品牌内部授权 | 可随资料版本新增对象；不得进入正式交付包 |
| `authorized-media` | 封面、正文和渠道配图 | 审核通过且声明可公开后，才能被正式包引用 | 引用固定到该对象版本 |
| `delivery-package` | 正式包或审阅稿的文件 | 持有该品牌内容权限的用户 | 不可覆盖；新导出使用新对象 |
| `report-snapshot` | 报告 HTML 与可复算 JSON | 持有该报告权限的用户 | 不可覆盖；新快照使用新对象 |
| `owned-export` | 本人数据导出文件 | 仅导出所属账号 | 不可覆盖；再次生成使用新对象 |
| `publication-evidence` | 人工核验截图 | 仅该品牌发布核验的授权用户 | 不可覆盖；重核验追加新对象 |
| `source-original` | M1 资料导入原件 | 工作区授权成员 | 抽取失败不制造正文；撤销后停止新下载 |

单对象上传上限默认 10 MiB，与 [S-M1-04](../specs/M1.md#s-m1-04) 的单文件上限一致。本人导出仍遵守现有按范围 8 MiB 的反馈上限。对象存储上线本身不提高这些上限，也不放宽“容量不足时阻止新上传、不静默删除历史”的规则。

允许的内容类型按类别限制：图片为 JPEG、PNG、WebP；交付包与报告为 Markdown、净化 HTML 和 JSON；本人导出为 UTF-8 JSON；资料原件为可提取文本的文档。加密文件、可执行文件和无法识别的类型拒绝写入。HTML 延续公共 SPEC 的净化要求，对象存储不执行上传内容中的脚本。

<a id="oss-authz"></a>

## 5. 权限、完整性与保留

1. 上传、下载、预签名和删除都在服务端重新校验会话和资源归属。其他账号、失权成员和没有该品牌授权的维护者得到与资源不存在相同的结果，响应里不出现对象键、桶名或密钥。
2. 正式交付包只打包允许公开的正文、来源说明和已审核的公开图片。内部附件、存储凭据和其他品牌的对象不得出现在包内。这是 [AC-M0-10-2](../specs/M0.md#s-m0-10) 与 [AC-M0-02-2](../specs/M0.md#s-m0-02) 在字节层的要求。
3. 每个成功对象记录 SHA-256 与字节数。读回校验不一致时，该对象对用户不可用。
4. 交付包、报告、导出和核验证据一旦标记完成，禁止用同一对象键覆盖字节。内容变更产生新版本和新对象；旧文件保持原字节，界面按原业务规则标失效或来源缺失。[AC-M0-10-1](../specs/M0.md#s-m0-10)、[AC-M0-12-3](../specs/M0.md#s-m0-12) 继续有效。
5. 已经下载到用户设备上的包不能远程召回。系统能做的是拒绝新的授权下载，并提示勿再使用。
6. 品牌冻结后拒绝新上传和普通下载。清除按已披露的保留期删除对象字节；保留的最小记录只有对象标识、类别、字节数、指纹、时间和删除结果，不含文件名、正文和预签名 URL。
7. 素材权利撤销或成员授权撤销后，新的预签名必须失败。历史引用和已发布链路保留，并按 [AC-M1-04-2](../specs/M1.md#s-m1-04)、[AC-M1-08-2](../specs/M1.md#s-m1-08) 生成或保持维护待办。
8. 人工核验截图只证明该次人工证据等级，不把对象存储地址当成公众可访问页面，不写入 `effective_at` 以外的公开核验结论。[AC-M0-11-3](../specs/M0.md#s-m0-11) 的状态区分保持不变。

<a id="oss-env"></a>

## 6. 环境变量

变量名在 SeaweedFS 与阿里云 OSS 之间保持不变。真实值只放在 gitignored 的 `.env.local` 或部署环境，不写入源码、`.env.example`、文档、Issue 或 `NEXT_PUBLIC_*`。

| 变量 | 含义 |
| --- | --- |
| `S3_ENDPOINT` | 服务端 SDK 访问的 S3 地址。本机 Next.js 进程使用回环地址 |
| `S3_ENDPOINT_BROWSER` | 为浏览器签名时使用的 S3 地址。须是浏览器实际能打开的主机 |
| `S3_REGION` | 签名区域。本地 SeaweedFS 使用 `us-east-1`；阿里云使用 OSS 地域 |
| `S3_BUCKET` | 桶名。本地桶为 `app-files` |
| `S3_ACCESS_KEY_ID` | S3 访问键 |
| `S3_SECRET_ACCESS_KEY` | S3 私钥 |
| `S3_FORCE_PATH_STYLE` | 本地 SeaweedFS 为 `true`；阿里云 OSS 为 `false` |

同一 Compose 网络中的应用把 `S3_ENDPOINT` 设为 `http://seaweedfs:8333`，并加入外部网络 `seaweedfs-mini`。这与宿主机回环地址、浏览器地址是三种调用方，不是三套实现。

文件浏览入口 `8888` 的基本认证只给运维查看，应用代码不读取该用户名和密码。

<a id="oss-non-goals"></a>

## 7. 范围外

- 不实现业务功能代码、迁移或页面。本文件只定需求。
- 不改写 26 项需求的验收定义，不勾选 M0/M1 任务。
- 不把对象存储地址当作公开网页、发布成功或效果提升。
- 不开放桶的匿名列举，不把 SeaweedFS 当前默认的 CORS `*` 当作浏览器直传的上线配置。
- 首期上传由 Next.js 服务端接收后再写入对象存储。浏览器直传放到 CORS 已限制为应用来源之后。
- 不在本需求中开通路由器端口转发、公网预签名或整机重启验收。
- 不接入邮件网关。导出完成仍使用现有站内结果，不新增发信。

## 8. 需求验收

实现顺序见 [对象存储开发队列](../tasks/issue-backlog-2026-11-21-oss.md)。实现阶段用 [对象存储 SPEC](02-对象存储功能规格-SPEC.md) 的 `OSS-AC-*` 验收软件行为，并回归所引用的 `AC-M0-*` / `AC-M1-*`。本地契约测试使用回环 S3 mock。连接本机 SeaweedFS 的检查只在开发环境显式执行，缺少 SeaweedFS 或阿里云账号时，自动化测试仍须通过 mock。切到阿里云 OSS 时，用同一客户端配置虚拟主机风格完成一次上传、下载和错误密钥拒绝；该检查不作为 CI 的必跑项。
