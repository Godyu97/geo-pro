## 3. 外部验证记录

对齐验收场景的六个字段。官方 API 与消费者入口分开记录。每次验证复制一张空表。

### 官方 API

| 字段 | 记录 |
| --- | --- |
| 能力/版本 | 观察对象、入口、模式、采集方式、模型版本或未知： |
| 验证条件 | 时间、目标/实际地区、会话、联网要求、账户可用权限： |
| 执行范围 | 固定题集、槽位数、成功/失败/未知、实际耗时： |
| 证据 | 原回答位置、引用完整性、联网发生依据。不把密钥写入本表： |
| 费用 | 预计上界、实际、待核对、币种： |
| 结论 | 通过的能力、不支持的能力、过期时间、退化处理： |
| 结果状态 | 未执行 |

M0 门禁要求的真实范围是 10 题 × 2 轮。未达到时保持阻塞。

### 消费者人工入口

| 字段 | 记录 |
| --- | --- |
| 能力/版本 | 入口、采集人、模式、模型版本或未知： |
| 验证条件 | 时间、目标/实际地区、新会话条件、许可： |
| 执行范围 | 固定题、成功/失败/未知、耗时： |
| 证据 | 可定位存证的位置。不粘贴不必要的个人信息： |
| 费用 | 人工工时、待核对费用： |
| 结论 | 通过、不支持、过期与退化： |
| 结果状态 | 未执行 |

M0 门禁要求的真实范围是 3 题 × 2 轮。未达到时保持阻塞。
