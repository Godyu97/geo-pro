# monitoring-runs Delta

## ADDED Requirements

### Requirement: 官方 HTTP 采样合同

系统 SHALL 只在服务端具备核准 endpoint、凭据、产品入口和可信单价表，且通道为同一未过期 verified 版本时发送官方 HTTP 采样。缺配置、入口不匹配、模型未知或能力过期时 MUST 拒绝，不得生成模拟回答或扣减额度。系统 MUST 分别记录原文、模型回执、联网触发和引用完整性。缺价、超时、受理未知或费用超上界时 MUST 进入待核对并保留预算上界，不得盲目重发。凭据 MUST NOT 进入日志、重定向目标或客户端包。

#### Scenario: 未配置或能力过期

- **GIVEN** 运行已经登记，但官方凭据缺失、产品入口不匹配或通道验证已过期
- **WHEN** 使用官方端口执行
- **THEN** 请求被拒绝，不产生模拟回答，也不写入额度扣减

#### Scenario: 十题两轮引用与联网

- **GIVEN** loopback 官方响应分别给出完整空引用、缺失字段、不支持引用和没有触发证据的联网
- **WHEN** 对 10 题执行 2 轮契约采样
- **THEN** 引用状态和联网触发被分开记录，未知联网不进入 required 分母，且不宣称真实通道已开通

#### Scenario: 超时与未知费用

- **GIVEN** 一个槽位超时，另一个槽位费用无法从可信单价表算出
- **WHEN** 执行完成并再次执行
- **THEN** 这两个槽位保持待核对和预算上界，系统不重复发送已超时的请求，响应中也不出现密钥
