# Proposal

## Why

Issue #2（B02）属于 M0 / R-M0-01、T-M0-01、S-M0-01 的认证基础子项。B01 已提供双语言和安全返回地址，但已有身份的登录入口、会话失效提示和认证故障恢复仍有缺口。

## What Changes

- 用服务端真实会话决定登录入口；有效会话直接进入合法返回目标，当前仅开放工作台。
- 区分未登录、认证未配置和服务不可用；提供双语言提示和显式重试。
- 工作台检测会话失效，返回登录并保留安全的位置、筛选和片段；恢复只导航，不重放动作。
- 验证注册、登录、退出失败、撤销/伪造/过期会话的读写拒绝，以及两种语言的布局和键盘行为。
- 不持久化认证表单或凭据；业务草稿和真实品牌引导由 B04（#4）联调，不实现虚构品牌分流。

## Capabilities

### New Capabilities

- `account-session`: 账号入口、会话授权及安全恢复的可观察行为。

### Modified Capabilities

无；当前 OpenSpec 主规格为空。

## Impact

修改既有 `src/lib/auth/`、账号/工作台壳层、双语言消息及认证/E2E 验证入口；新增本项交付记录。不新增依赖、表结构、业务 DAO 或缓存后端，不改变 Better Auth API 地址。沿用 PostgreSQL 认证基线；SQLite、Redis、OAuth、邮件验证/密码恢复、品牌业务及 M1/M2 不在范围内。
