# 执行和恢复监测并核对本人用量

## Why

排队运行已经可以登记，但采样尚未开始。负责人需要在隔离传输上执行、暂停、继续、取消并核对费用，同时查看本人的额度变动。真实供应商仍未接通。

## What Changes

- 为已登记运行增加可替换传输、Attempt、采用结果和费用状态。
- 支持正常完成、部分失败、暂停、继续、取消、晚到和待核对。
- 在设置中按本人范围分页列出额度、预留、结算和关联运行。
- 官方 API 端口保持关闭，公共界面不生成模拟成功。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `monitoring-runs`：在排队登记之上增加执行、恢复、费用核对和本人用量。

## Impact

影响监测领域、额度账本的执行期读写、运行详情、设置用量页，以及 PostgreSQL 与 SQLite 的运行表结构。真实供应商接入不在本次范围。
