# Design

## 范围

M0 / R-M0-03。题集放在 `src/features/prompts/`，页面和接口保持薄层。草稿与冻结版本分开，正式运行以后再冻结重复次数和通道条件。

## 数据

- `prompt_draft` 每个品牌一行，保存修订号、基准冻结版本和题目 JSON。
- `prompt_set` 以品牌和版本 ID 为主键，题集族加版本号唯一，并外键到品牌实体版本。最近版本使用 `(brand_id, created_at, id)` 索引。
- `prompt_reference` 以品牌、冻结版本、题目和消费方为主键，并用 `(brand_id, question_id)` 判断题目是否只能停用。
- 双方言 Schema、迁移和全量 DDL 一起更新。清除品牌内容时显式删除这三张表。没有题集的本人导出保持原结构；有题集时随品牌范围导出。

## 规则

空白折叠后完全相同则拒绝。字符二元组 Jaccard 达到 0.72，或较短题被较长题包含且长度比至少 0.75 时只提示。负责人确认后可保留。品牌名、别名和竞品按规范化文本匹配；诱导或指定答案的发现、场景、约束题改为探索题。主指标只统计已确认且不含品牌词的发现、场景和约束题。冻结要求至少 3 个主指标题，已确认题目的地区和业务语言一致，总数不超过 10。

## 验证

DAO 测试覆盖双库升级、验收场景、越权和查询计划。浏览器验收覆盖两种界面语言、三种宽度、键盘和关闭真实收集的边界。
