# brand-deletion Delta

## MODIFIED Requirements

### Requirement: 到期清除与断点重试

系统 MUST 仅在当前恢复期限届满后，由受控服务端按有界批次处理冻结品牌。正文、导出和费用各有可追溯结果。已开始清除的品牌不能恢复；已完成步骤须幂等跳过。正文清除 MUST 先删除页面检查、任务证据和优化任务，再删除优化发现，并清除其余 M0 业务正文。存在未核对费用时仍阻塞清除。清除后仅保留最小费用凭证，且旧的品牌业务导出不可继续读取。

#### Scenario: 到期与并发恢复

- **WHEN** 清除与恢复请求竞争，或任务遇到未经确认的品牌
- **THEN** 只有合法转换成功，未到期的品牌资料保持可恢复

#### Scenario: 局部故障

- **WHEN** 阶段失败或费用仍待核对
- **THEN** 记录已完成步骤与剩余范围，重试跳过已完成步骤

#### Scenario: 含优化任务的品牌到期

- **WHEN** 品牌含有页面检查、优化任务、事实链和其他 M0 正文且费用已核对
- **THEN** 清除不因外键失败，正文被移除，重跑结果不变，最小费用凭证仍可读取
