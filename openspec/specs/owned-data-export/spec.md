# owned-data-export Specification

## Purpose

让品牌负责人在账户设置中预览当前可导出的数据范围，取回自己有权读取的个人资料和品牌档案，并能判断哪些范围未开放或生成失败。下载随当前会话、归属和数据状态核验。

## Requirements

### Requirement: 设置内预览和选择本人数据

系统 SHALL 在 zh-CN 与 en 提供本人数据导出范围。个人资料包含称呼和登录邮箱。品牌范围包含本人可读的活跃及归档档案、其实体版本和已保存草稿。界面明示尚未开放的范围与可用状态。

#### Scenario: 品牌范围尚未开放
- **WHEN** 常规环境的用户预览或直接请求未开放的品牌范围
- **THEN** 界面说明范围不可选，接口拒绝该选项，用户仍可准备个人资料

#### Scenario: 选择范围并切换界面语言
- **WHEN** 本人通过设置预览并选中可用范围，然后切换界面语言
- **THEN** 原选择、身份和位置保留，界面按新语言显示且生成须由本人触发

### Requirement: 保存最近一次生成结果

系统 MUST 记录本人最近一次生成的范围、语言、时间与结果。部分失败时只允许下载完整生成的范围，并在界面和附件中标出失败范围。没有生成任何范围时不提供文件。

#### Scenario: 选定范围完整生成
- **WHEN** 所选范围均能读取并形成附件，含合法但为空的集合
- **THEN** 界面显示已准备，UTF-8 JSON 可重新读取且记录导出语言。中文语言使用可往返的中文文件名，原始名称和业务语言保留

#### Scenario: 部分范围读取失败
- **WHEN** 所选范围中只有部分完整生成
- **THEN** 界面显示部分完成及失败的范围，附件记录相同结果。生成结果写入失败时反馈不可用，原生成记录不变

#### Scenario: 并发生成或重试
- **WHEN** 同一账号的生成请求使用同一旧生成记录并发提交或重发
- **THEN** 最多生成一个新记录，其他请求可重新加载确认结果

### Requirement: 每次下载重新授权

系统 MUST 在生成和下载时核验当前会话及数据归属，仅输出显式选择且核验通过的字段。认证凭据、会话、维护记录和未实现的业务数据不可进入附件。下载响应不可被共享或缓存。

#### Scenario: 账号越权或失效会话
- **WHEN** 匿名、失效会话、其他账号或未获归属的维护者请求导出标识
- **THEN** 系统拒绝访问，其他账号的资源与未知资源给出相同响应

#### Scenario: 生成后内容或访问权变化
- **WHEN** 选定且已生成的源内容被移除、失权或发生修订，或本人生成了新记录
- **THEN** 旧地址无法取回原内容，界面提供按当前范围重新生成的操作
