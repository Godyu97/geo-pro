# competitors

固定竞品集与已观察提及的份额在 `commands.ts` 和 `competitor-share/rules.ts`。同一回答里每个品牌只计一次，在共同可判断子集里分别计算题等权份额与池化份额；零提及题保持 N/A 并保留覆盖，缺失题目编号的回答不进入等权均值，竞品集换版后分段，无序输出不产生名次；有序观察按品牌在同一可判断分母上给出上榜率、首位率与仅统计已上榜样本的条件平均位置（未上榜不记 0 或队尾）。

来源复核记在 `source_inspection`：页面有效、可读且归属明确时区分正向支持（`supports`）与可判断非支持（`does_not_support`），不可读、失效、归属不明或未复核保持 `unknown` 且历史 `unknown` 不回填；来源区在可判断分母上展示第三方支持率（无可判断时显示 `N/A` 与原因）。研究 Brief 拒绝只替换品牌名的文案，并保留来源 ID。双语页面在 `/dashboard/monitoring/competitors`。这里不抓取外部页面，也不把份额显示成排名。
